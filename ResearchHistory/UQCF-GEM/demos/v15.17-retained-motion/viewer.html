What does closure mean?

Write E for the fixed retained-algebra projection and U for the supplied finite motion. Exact descent of unpruned motion requires E(UρU†)=E(UE(ρ)U†) for every input ρ. Otherwise two inputs represented by the same retained state could require different retained outputs. No rule of that retained input alone could reproduce both counterfactual outputs.

For this finite unitary model, closure is equivalent to U preserving the retained algebra as a set. Preserving every existing record identity is stronger: U must fix each central record projector. A permutation of sectors is reversible and algebra-preserving but is not preservation of each fixed record label.

Two lawful alternatives that must not be conflated

Actually pruning first and then applying U is always a valid quantum process. Nonclosure does not make that process illegal; it prevents representing the unpruned process without its discarded distinctions.

Alternatively, transport the retained projectors as P′=UPU†. Then E′(UρU†)=UE(ρ)U† exactly. This changes the retained description covariantly, without recovering erased information. All 96 declared motion/mask cases pass that operator identity.

Inserting a new projection between motion steps also changes the operation. In the displayed two-sector control, projecting only at the end versus between two rotations changes the final state by trace distance 0.5. A numerical display step must not silently become a pruning event.
