What is actually derived within this supplied model?

The fixed complete instrument has orthogonal rank-one input effects. For any selected set S of record bits, pulling partial record pinching back through the encoding gives a conditional expectation E_S(ρ)=Σ P_sρP_s. Its exactly recoverable input observables are the block-diagonal algebra Σ P_s A P_s. The projectors are computed from the original branch operators, not fitted to the desired result.

With k pinched bits, there are 2^k blocks of matrix size 2^(4−k). Partial pinching therefore can leave noncommuting quantum observables inside each block. Pinching all four retains only a classical algebra. None of those alternatives selects an actual outcome.
