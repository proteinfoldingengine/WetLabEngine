# Unit barriers with exactly two internal vertices
Status: proposed proof, subject to independent review and preregistered validation.

Within the admitted no-unary category, let T(a,b) have root degree a>=2, a unique internal child v of degree b>=2, and l=a-1 side leaves. There are k>=2 indexed labels; root support is K, every nonroot support is nonempty and contained in its parent's. A primitive move changes one label incidence while preserving admission. Let q(u) be the minimum number of labels hitting all child supports (zero at leaves). Fix any attained profile with q(root)=r, q(v)=s. Define each barrier as its own scalar path minimum over the complete admitted graph. Then all states of this fiber are connected within total L1 deviation at most1. Consequently each of B1,Binf,Bs is0 within an exact component and1 between distinct exact components. The separately nested LEX triple is likewise (1,1,1) between distinct components.

## Star lemma and its direction
Use the v16.43 theorem and its constructive normalization, for any ordered palette of k labels and m leaves with hitting number q: shrink onto a minimum hitting set, relabel its colors, and normalize singleton colors to the first q distinct anchors and remaining leaves of the first color. This has cost0 unless m=k=q. In that fully packed case the partition transposition path has hitting number q or q-1 ONLY: start with distinct singleton colors, add the exchanged label at one leaf, add the old color at the other leaf, then delete each old incidence to complete the exchange. Thus it never increases q. For m=1 normalization is exact at q=1 by adding the chosen label if needed and deleting the others. For a singleton palette the admitted star state is unique. These degenerate cases do not invoke the star theorem outside its stated domain.

## Construction for every state
Write S for v's support and t for the minimum hitting number of just the l side leaves. The root has these children plus S, so t<=r<=t+1; also |S|>=s. Every operation below is a single admitted incidence move. All canonical labels below are zero-based.

1. Hold S and the b inner leaves fixed. Apply the star normalization to the side leaves with palette K and target t. If not fully packed, side hitting stays t; root hitting is t or t+1 and therefore differs from r by at most1. If l=k=t, the initial root value is r=t (S is nonempty and K has size t). The downward-only packed path keeps side hitting at t or t-1; root hitting is between t-1 and t, because no cover can exceed k=t. The inner value stays s. At completion side leaves have colors 0,...,t-1 on the first t anchors and0 on the rest.

2. Choose the final support S*. If r<=l, take S*={0,...,s-1}, containing0. If r=l+1, the root achieves its number of children; their supports must be pairwise disjoint, since a shared label could hit two children and reduce the cover. It follows that t=l and k>=l+s. Set S*={l,...,l+s-1}, disjoint from the canonical side palette. This is feasible and has size s.

3. Add each missing label of K to v. Nothing changes in the inner child supports, hence the inner hitting number remains s. Root hitting lies in {t,t+1}, so root deviation is at most1.

4. If k>s, apply the exact star normalization to the inner leaves, ordering the full palette with S* first. The spare label k>s excludes the fully packed exception, regardless of b. Thus inner hitting remains s. The root depends only on v's fixed support K, not on its leaves. The inner leaves now use exactly S*. Delete all labels outside S* from v; these labels occur in none of its children, so removal is admitted. Inner hitting remains s, and root hitting stays in {t,t+1}. If k=s, then S=K, and the maximum-root-degree case is impossible by k>=l+s. Thus S*=K and we postpone inner normalization; no operation in this step is needed.

5. If r<=l and t=r-1, then r>=2 and l>=r supplies a redundant0 side leaf at index r-1 (the first r-1 anchors already use 0,...,r-2). Add color r-1 to this leaf and remove0. The anchor at index0 retains0. Side hitting rises from r-1 to r; throughout this two-move step it is r-1 or r. Since S* contains0, root hitting is exactly the side hitting: a minimum side cover can contain0, as witnessed by the unchanged singleton0 anchor and the explicit singleton/one-doubleton form. Hence root deviation is at most1. If t=r, nothing changes. The final side coloring is the canonical r-color one and root hitting r. If r=l+1 instead, the l canonical distinct singleton side colors are disjoint from S*, so root hitting is already r.

6. Only now normalize inner leaves inside the fixed palette S*, using its increasing label order. Root support data no longer change, so its value stays exactly r. If b>s, the normalization is exact; if b=s=|S*|, the star lemma allows inner deviation1. If s=1, all inner leaves already have the unique singleton support. The final state is canonical: side colors determined by r,l, inner support S*, first s inner leaves take its distinct labels and remaining leaves its first label.

At all times either the inner value is exactly s and root deviation is at most1, or root is exactly r and inner deviation is at most1. Leaves always have value0. Therefore total L1 deviation is at most1. Both Binf and Bs are bounded by the same path. Each state reaches the same canonical endpoint; reverse the second normalization to connect any pair. Distinct exact components cannot have a zero-cost path for any of the three objectives, so integrality gives the matching lower bound1. A path whose independent maxima are all<=1 also gives LEX=(1,1,1) between distinct components, without identifying LEX with independent optimization in general.

## Scope
This proof is for every admitted two-internal-vertex tree and any indexed-label count k>=2. One-internal-vertex stars were handled by v16.43. It makes no claim for trees with three or more internal vertices, where shared ancestor effects may prevent this scheduling. The universal unit-barrier conjecture and a genuine nonunit admitted witness remain unresolved unless separately established. Finite results validate implementation and the frozen universe, not the universal quantifiers of this proof.
