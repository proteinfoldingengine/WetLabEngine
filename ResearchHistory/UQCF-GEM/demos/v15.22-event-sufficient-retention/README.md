## 1. Keep the full branch-output contract explicit

At an already-realized record context h, restrict to its current support P_h.
Its dimension is d_h=16/2^|h|. Earlier records are fixed in this comparison.
The inherited instruments preserve P_h and have compressed operators

    K_(e,b) = P_(e,b) U_e,   b=0,1,
    J_(e,b)(rho) = K_(e,b) rho K_(e,b)^dagger.

U_e may depend on previously realized reads, exactly as in v15.14. Only ready
events are admitted. We require equality of subnormalized quantum branch states,
not just their traces: this includes the quantum information remaining in all
unmeasured degrees of freedom within the current sector. Equal maps then also
agree with a spectator reference system. A weaker endpoint/statistics contract
can admit more reduction and must not be confused with this requirement.

## 2. Constructive factorization for one specified next event

The input effects F_b=K_b^dagger K_b are orthogonal projections resolving I_d.
They determine the conditional expectation

    E_e(rho) = sum_b F_b rho F_b.

The exact factorization is

    K_b F_c = delta_(b,c) K_b,
    J_(e,b) E_e = J_(e,b).

Thus the event-specific preprocessing preserves every branch's probability,
conditional quantum output, and reference correlations. It removes only input
coherence that this specified event already discards. No gain correction is
needed. Its input observable algebra is M_(d/2) direct_sum M_(d/2), with real
Hermitian dimension d^2/2, including identity. This does not reduce the Hilbert
carrier size and is not an entropy count.

The map is canonical once the event instrument is supplied; it does not select
that instrument physically. It is also a most-forgetful sufficient preprocessing
in the following precise sense. If a same-sector CPTP map Phi obeys
J_b Phi=J_b for both branches, then

    E_e Phi = sum_b U_e^dagger J_b Phi(.) U_e = E_e.

E_e is therefore obtainable from every such Phi's output. This is a comparison
of preserved information under postprocessing, not a unique fundamental collapse
law. Identity is also sufficient; the equations alone do not demand an event.

This restores the earlier RAS construction as an explicit factorization of a
supplied instrument. RAS and RCR remain distinct: E_e has no outcome argument
and does not add an actual record. A declared outcome still enters only through
the unchanged prior `advance` operation. We do not count the factorization as an
additional physical pruning event or a new interval of time.

## 3. A common preprocessor for two ready events is much more restrictive

At each two-ready context in this model, the two binary effect families commute,
and their four joint projectors have equal nonzero rank d/4. Write A_e for the
full within-effect-sector algebra required by event e.

If Phi preserves the entire e instrument, Phi* fixes every element of A_e:
those elements are linear sums of K_b^dagger X_b K_b. Phi* is unital and completely
positive. Every fixed unitary belongs to its multiplicative domain [1]. Hence,
if Phi preserves both complete instruments, Phi* fixes the algebra generated by
A_e and A_f, not just their linear union.

These two algebras generate M_d here. In a common eigenbasis with sector labels
(a,b), take arbitrary basis labels i,j. There is a label k whose first bit is
that of i and second bit that of j. Then

    E_ik is in A_e,  E_kj is in A_f,  E_ik E_kj = E_ij.

Every matrix unit is generated. Consequently

    J_(e,b) Phi = J_(e,b) and J_(f,c) Phi = J_(f,c) for all b,c
        => Phi = identity on M_d.

The exact implication uses the finite argument and the standard multiplicative-
domain theorem, not an enumeration of all possible CPTP maps. Numerical tests
verify the joint projectors and all matrix-unit products in this construction.
A general observable-algebra perspective is given in [2]. These references do
not validate the project's physical ontology or establish novelty priority.

This is not measurement incompatibility: the ready events commute. Nor is it a
ban on information loss or on irreversible physical events. It is the exact
all-input, same-sector, unchanged-instrument, complete-output contract BEFORE
choosing which event happens next. Different encodings, restricted input sets,
permitted output changes, approximations, or specifying a batch are different
problems. No fundamental causal order is derived by imposing this interface.

## 4. Probability-only and batch controls prevent overclaiming

At the root, form opposite-phase states spanning joint effect sectors (A=0,B=0)
and (A=1,B=0). The B1 outcome is certain for both. A1-specific pinching preserves
that B1 probability, but changes its remaining normalized quantum state by trace
distance 0.5. Two B1 outputs that were mutually distinguishable with distance 1
become identical. The program therefore rejects probabilities alone as evidence
of exact preservation of an entire branch instrument.

Conversely, if BOTH events are actually executed as a specified batch, their
joint pinching preserves all final two-event branches. The intermediate state
contract has been weakened. This does not evade or contradict the open-next-
event result. All seven two-ready contexts include this batch control.

The inspector varies a declared convex mixture (1-a)id+a E_A1. Each is CPTP.
A1 branches remain unchanged for all 41 settings, the displayed B1 probability
also stays fixed, while its output-state distance becomes a/2 and the remaining
phase-pair distance becomes 1-a. This is not a physical response law: a merely
indexes explicitly supplied comparison maps. No actual outcome is sampled.

## 5. Integrated coverage and measured results

All five inherited permissible schedules and sixteen outcome scripts were used.
The 45 unique realized-record contexts consist of 16 terminal contexts and 29
nonterminal contexts: 22 with one ready event, seven with two. Terminal contexts
impose no next-event contract and are not used to authorize arbitrary future loss.
There are 36 ready event/context pairs and 72 complete single-branch maps.

For all 80 histories, the matching E_e was inserted immediately before each
supplied event. All 320 resulting branch states, joint masses, and conditional
weights agree with the unmodified execution. Local maxima:

- full branch Choi-map discrepancy: 1.51e-15;
- Kraus factorization error: 4.78e-15;
- matrix-unit multiplication certificate error: 6.74e-15;
- final two-event-batch Choi discrepancy: 8.64e-16;
- integrated normalized-state distance: 1.94e-15;
- integrated joint-mass error: 1.78e-15;
- integrated conditional-weight error: 2.44e-15.

The pair-algebra argument is checked with 448 matrix-unit certificates across
all seven two-ready contexts. Identity tolerances are 1e-10 or tighter. The full
proof is all-input; the finite histories illustrate the integration, not replace
that proof. Choi matrices are normalized by the input dimension and compared in
Frobenius norm. State distances are trace distance; those are different metrics.
