# Full coherence family: fixed-parameter boundary classes

Let Lλ=((1+λ)/2)L+ + ((1−λ)/2)L−. The channel I+sLλ has weights (1−s), s(1+λ)/2, s(1−λ)/2 on I, Ad(U+) and Ad(U−). Nonnegativity and normalization hold on 0≤s≤1, −1≤λ≤1. This is the existing source family with fixed total channel-mixture strength, not a new parameter selected from a desired output.

The exact global density path is affine in s and λ in its derivative. The connected moment matrix subtracts a product of two one-body moments, so it has form C+s(V0+λV1)+s²(W0+λW1+λ²W2). Direct symbolic construction and ±1 endpoint checks tie these coefficients to the earlier physical paths.

If N(λ)=(I−CC⁺)V(λ)(I−C⁺C)=λN+ with rank(N+)=k>0, every fixed nonzero λ has a first-order rank lower bound r+k. If all polynomial coefficients remain in the same two-dimensional plane when r+k=2, or r+k=3 is the full ambient dimension, this lower bound saturates for all sufficiently small positive s (the neighborhood may depend on λ). The one-sided canonical polar limit is polar(C)+sign(λ)polar(N+).

At λ=0 the first-order lower bound supplies no information beyond r. Exact polynomial rank in s is therefore checked separately. If it equals r, an r×r minor nonzero at s=0 stays nonzero in a neighborhood and no larger minor can appear. Constant rank ensures continuity of the canonical polar factor there, so the limit is polar(C). A higher polynomial rank would require a separate slower-mode analysis and cannot be silently assigned the baseline limit.

The three fixed-λ boundary classes have squared Frobenius distances k from the zero class and 4k between the positive and negative classes. The limit jumps as a function of the source coherence sign, while the underlying density-state channel family is a smooth polynomial in both parameters. This is not a claim of a uniform s-limit, an interchangeable pair of limits, or a uniquely defined joint limit as (s,λ)→(0,0).

For the two channel orders, identical baseline matrices plus positive normal scaling give identical limits at each fixed nonzero λ; constant rank gives agreement at zero. This only establishes order agreement within a fixed source choice. It cannot select a source or replace source-choice dependence with intrinsic baseline data.

This analysis localizes an obstruction in the canonical polar extraction at the retained sixth-edge rank boundary. It does not exclude every smooth state observable, enriched description or alternative geometry. No fitted completion, null-space alignment, determinant correction, source-emergence law or gravity correspondence is introduced. Time is pruning / ordered recoverability update; s is a mixture strength.
