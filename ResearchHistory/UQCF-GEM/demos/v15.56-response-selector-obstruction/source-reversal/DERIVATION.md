# Same baseline, distinct admissible approach limits

Let P=ZI and Q=XX. They are Hermitian unitaries and anticommute, hence U±=(P±Q)/sqrt(2) are Hermitian unitaries. E±,s=(1−s)I+sAd(U±) is CPTP for 0≤s≤1. Both compositions with the same middle and preparation channels have the same s=0 baseline. The exact transfer relation L−=2L0−L+ follows from the convex source decomposition already present in 15.98. It is checked against direct Pauli-basis conjugation, not assumed from floating arithmetic.

For each actual connected-matrix polynomial C±(s)=C+sV±+s²W±, compute N±=(I−CC⁺)V±(I−C⁺C). If N−=−N+≠0 and both ranks saturate at r+k, the 16.09 limit theorem gives B±=polar(C)±polar(N+). Consequently B+−B−=2polar(N+) and its squared Frobenius norm is 4k, because a rank-k partial isometry has k unit singular values. The source choices are actual physical channel paths, not subtraction of two paths presented as a physical state.

Two different limits along admissible paths to the same baseline prohibit a continuous baseline-only extension that agrees with this canonical polar readout along both paths. This is a statement about these retained sixth-edge matrices and their readout; it neither proves that every possible enriched readout is impossible nor derives which source must be used. An extra source choice can label an approach, but would remain extra data unless selected by an independent law.

A failure of exact normal reversal is a negative result for this test, not proof of equality. Rank saturation is indispensable; uncertified paths are labeled instead of assigning a missing polar mode. No determinant correction, fitted singular-value cutoff, or arbitrary kernel frame is introduced. Time remains pruning / ordered recoverability update; s is only channel-mixture strength.
