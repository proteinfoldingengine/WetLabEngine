# v16.33 — Consistency-quotient kernel and minimal representatives

Parent: v16.32 published head `511f9bc17d43ab70d60a71e73fac746ce66484e4`.

## Question
v16.32 proves that the closed value-level signature is noninjective because redundant labeled incidences can vary invisibly. Characterize that noninjectivity itself.

For a fixed rooted lineage tree and indexed retained cover Y, define q(Y)=tau(Y), equivalently the v16.32 frozen value-level signature because h and normalized component values are functions of tau.

Two legal same-union covers are q-equivalent when q(Y)=q(Z).

## Gate A — single-incidence invisibility
For a legal leaf incidence (i,c) removable from view i without changing the union, with parent v, prove/test the exact condition for q(Y\{(i,c)})=q(Y).

Candidate:
the deletion is invisible iff tau_v is unchanged; all other tau_u are automatically unchanged by parent locality. Equivalently, at least one old minimum child-cover of size tau_v survives after deletion.

This is inherited from v16.26 but now interpreted as the one-step kernel condition, not as a temporal increment.

## Gate B — equivalence generated by invisible deletions?
Adjudicate whether any two q-equivalent covers in the same union can be connected through a sequence of legal q-preserving single-incidence deletions/additions that never leaves their q-class.

Outcomes:
GENERATED_BY_LOCAL_MOVES / COUNTEREXAMPLE / UNRESOLVED.

A counterexample requires exact q-equivalent covers and exhaustive proof that no q-preserving move path connects them.

## Gate C — canonical minimal representative
Within each q-equivalence class, order covers by labeled incidence inclusion. Determine whether there is a unique inclusion-minimal member.

Outcomes:
UNIQUE_MINIMAL / MULTIPLE_MINIMA / CONDITIONAL.

If multiple minima occur, publish the smallest exact class and distinguish:
- multiple labeled minima related only by allowed relabeling symmetry;
- genuinely distinct minima even after the declared symmetry.

Do not choose a lexicographically preferred minimum and call it canonical.

## Gate D — what is preserved by minimization
For every minimal representative, verify same union, prefix legality, exact tau, h and component values. Record incidence count removed from nonminimal class members.

## Bounded universe
Enumerate all indexed legal covers of each rooted unordered tree through five vertices with at most four views and whole-tree union. Group by exact tau. For each class:
- construct the graph of legal one-incidence q-preserving moves;
- compute connected components;
- compute all inclusion-minimal members;
- quotient minima by parent-preserving lineage relabeling plus indexed-view-preserving set transport; do NOT permute view identities unless explicitly declared.

Publish counts of classes, nontrivial classes, disconnected q-classes, classes with multiple minima, and smallest witnesses.

## Rejecting controls
Reject changed union, non-prefix deletion, deletion that changes tau, fabricated minimality, omitted class members, treating storage order as incidence identity, and a fake unique minimum where two incomparable minima exist.
