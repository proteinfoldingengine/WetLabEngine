# v16.33 — Consistency-quotient kernel and minimal representatives

## Results

Gate A — single-incidence kernel: **DERIVED**.
A legal same-union leaf-incidence deletion is invisible to q=tau iff the affected parent's minimum child-cover cardinality is unchanged, equivalently iff at least one old minimum cover survives the deletion. All other tau coordinates are unchanged by parent locality.

Gate B — are q-classes generated by invisible one-incidence moves? **COUNTEREXAMPLE**.
The bounded exact audit contains q-equivalence classes that are disconnected in the graph whose edges are legal one-incidence moves preserving q. Therefore two covers can have identical consistency quotient while every route between some class components must temporarily leave that q-class. Equality in the quotient is strictly coarser than path connectivity under elementary invisible moves.

Gate C — canonical inclusion-minimal representative? **MULTIPLE_MINIMA**.
Nontrivial q-classes can contain multiple incomparable inclusion-minimal labeled covers. No canonical minimum is selected by q alone. A deterministic lexicographic choice would add convention rather than discover structure.

Gate D — minimization preserves exactly the declared quotient.
Every class member and every minimal representative has the same union and exact tau by construction; h and v16.31 value-level component data therefore agree as well. What differs is labeled retained incidence.

## Interpretation

v16.32 showed that the consistency quotient forgets redundant labeled incidence. v16.33 sharpens that statement:

1. Some redundancy is removable locally without changing q.
2. But q-equivalence is not exhausted by chains of such local invisible moves.
3. A q-class need not possess a unique minimal retained cover.

So the quotient has genuine many-to-one fibers with internal combinatorial structure. Calling those fibers a physical gauge orbit would require additional physical justification and is not done here.
