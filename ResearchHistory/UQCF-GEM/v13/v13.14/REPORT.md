If both `rho` and `P` belong to the exchange/permutation commutant, then that unital *-algebra is closed under:

- `log rho`;
- addition with `sP`;

`rho_s ∝ exp(log rho+sP)`

Fresh finite-flow projection errors are all below

`4.166e-16`.

So the exchange Schur-Weyl state is also an exact ETL state **when the source itself stays in the exchange algebra**.

`C_N ~ 4^N/(sqrt(pi) N^(3/2))`.

`H_N = direct_sum_J V_J tensor M_J`.

`direct_sum_J End(V_J tensor M_J)`,

Its Hermitian/operator dimension is

`D_N = sum_J ((2J+1)m_J)^2`.

`D_N = binom(2N,N) (3N-1)/(2N-1)`.

`D_N ~ (3/(2 sqrt(pi))) 4^N / sqrt(N)`.

`{exchange, collective SU(2), one site-local Pauli}`

`End((C^2)^tensor N)`.

**one site-resolved frame observable is enough to restore the full operator algebra.**
