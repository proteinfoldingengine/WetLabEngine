# Scientific closure requirements

These requirements govern every numbered retained-research stage. They are user requirements, not optional recommendations.

- Start from the exact verified integrated parent. Record both workflow SHA and checked-out scientific SHA.
- Commit prospective preregistration before new scientific execution. Disclose all already-known exploratory findings; never relabel them preregistered after the fact.
- Freeze mathematical objects, primary objectives, diagnostic objectives, full enumeration domain, competing outcomes, resource rules and stopping rules.
- Use algorithmically independent production and verification. Reconstruct the entire canonical universe and require exact identity equality, not supplied-record validation or count checks alone.
- Include substantive rejecting controls: missing, duplicated and substituted records; wrong values; invalid states/moves; false provenance/coverage. Preserve genuine RED evidence and failed runs.
- Provide typed mathematical arguments and distinguish general proofs, bounded evidence and unresolved propositions. No finite no-counterexample result is a universal theorem.
- Run the complete inherited foundational stack with pinned dependencies on GitHub. Inspect exact logs.
- Upload source, complete scientific certificates, logs, metadata and checksums as execution artifacts. Freshly reproduce deterministic scientific bytes in the publication job.
- Commit durable scientific evidence and verified manifests to GitHub; inspect downloaded artifact digests, not just upload success.
- Mark PR ready only after review, scientific verification and publication closure. Merge the verified head and audit the actual merge SHA, including replay, manifests, coverage and inherited stack.
- Never use CLOSED/CERTIFIED for a stage before the post-merge audit passes. Report every missing requirement explicitly.
- For barriers, primary B1, Binf and Bs are three INDEPENDENT scalar minima. LEX_BARRIER is a separate diagnostic. Their bounds need not be jointly attained by one path.
- Time is pruning / ordered recoverability update. Combinatorial barriers do not imply physical energy, action, metric, gravity or fundamental time.

Future agents must continue the complete closure chain within the user's authorized scope; recording a plan or contract does not resolve a requested run.
