## Independent derivation and assessment

1. **Events and floors.** At each labelled root, additions lie in `C_i minus A_i` and deletions in `A_i minus C_i`. These sets are disjoint, and each incidence has exactly one event. Thus any permutation executes genuine toggles without a separate presence/absence eligibility condition; common incidences stay fixed, and the terminal support is exactly `C_i`. At prefix s, cardinality is `|A_i| + N_i+(s) - N_i-(s)`, so the stated floor inequality is necessary and sufficient. This neither forces root completion before switching roots nor imposes support size equal to the floor. Upper support size is already bounded by the fixed palette.

2. **Exact pair intervals, including transient witnesses.** Fix a two-label set H. A common H incidence makes its root meet H at every prefix, so assigning that root an empty protection interval is exact. Otherwise the root misses H precisely after the last initially present H label is deleted and before the first destination H label is added. These are exactly `d_i(H) <= s < b_i(H)`, with defaults 0 and n+1. The deletion-time endpoint is included because the state is taken after its event; the addition-time endpoint is excluded for the same reason. If additions precede the final deletion, the interval is empty. Roots missing H at both endpoints protect permanently; roots meeting H at both endpoints can protect transiently when their H incidences differ and the floor permits the gap. The given one-root illustration has a retained label z, hence deletion before addition respects floor one. It is properly presented only as an interval illustration. The formula also handles n=0 and unchanged roots without an omitted boundary case.

3. **Theorem I11 is genuinely if and only if.** Positive floors give nonempty supports. Exact-four endpoints imply `|P| >= 4`, so any transversal of size at most two can be enlarged to a two-label transversal. Therefore `tau(X) >= 3` is equivalent to every pair H missing at least one root. The interval calculation identifies precisely every such missing-root witness at every prefix. Covering all integer prefixes by the intervals for each pair, jointly with every floor inequality for that same permutation, is consequently both necessary and sufficient for a native destination-directed lower-guard path. All pairs share one event permutation; allowing a different ordering for each pair would invalidate the criterion, but the candidate expressly forbids that interpretation.

4. **Exact-four boundary redundancy.** If a pair misses no root, it is already a transversal, contradicting tau=4. If it misses only one labelled root, positive floor supplies a label in that root; appending it yields a transversal of size at most three, again a contradiction. Thus each pair misses at least two roots at either endpoint. The interval formulas translate these facts exactly to at least two intervals covering prefix 0 and at least two covering prefix n. The protecting root sets at the two endpoints need not coincide. This proves endpoint redundancy only; it does not bridge the intermediate prefixes or guarantee compatible scheduling. The complementary formulation is also sound: a triple is not a transversal exactly when some complementary block contains it, and floors become complementary-block capacity bounds.

5. **Termination is conditional, not an existence argument.** For an already feasible permutation, `n-s` is a nonnegative integer decreasing by one at every primitive; its complete execution reaches the labelled destination after n events. This does not ensure that an arbitrary partial safe schedule has a safe continuation, nor that some globally feasible permutation exists for every endpoint pair. The candidate explicitly states both limitations. Its blocker identifies the correct outstanding alternatives: a joint existence/extension theorem for all declared endpoints, or an admissible endpoint pair with a rigorous exclusion of every permutation in this class.
