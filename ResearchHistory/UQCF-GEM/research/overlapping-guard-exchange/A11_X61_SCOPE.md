## Already-known deductions disclosed before candidate freezing

For an ordered partition of the actual roots into batches B_1,...,B_h, define boundary j to have C_i for processed batches and A_i for later batches. If every boundary has an actual hitting set K_j of at most four labels, then within batch j one can:
1. add all C_i minus A_i incidences while K_(j-1) remains valid;
2. switch covers after all additions;
3. delete A_i minus C_i while K_j remains valid.

For a physical pair D, a root avoiding D at both endpoints remains an actual union witness. Otherwise let O_D be old avoiding roots and T_D new avoiding roots. If some v in T_D lies in an earlier batch than some u in O_D, then u protects through v's entire batch and completed v protects all later batches. This appears to give one joint direct-band path, actual next edits, exact restoration and the endpoint Hamming minimum without requiring a cover to hit both endpoints of each active root.

This is unreviewed reasoning, not an accepted theorem.
