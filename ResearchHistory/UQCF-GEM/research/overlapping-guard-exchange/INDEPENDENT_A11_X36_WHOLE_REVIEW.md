### X36I: exactness, ownership and next-exchange existence

With exactly q nonempty roots, a transversal of size at most q always exists by selecting one label from each root. If any two actual roots share a label, that label plus one label from each other root is a cover of size at most `q-1`. Thus exact q implies pairwise disjoint supports. Conversely, q disjoint nonempty supports require q labels. This is a complete equivalence in `r=q`; it is not valid for arbitrary arity, and the candidate does not use it there.

At a disjoint boundary each palette label has one actual owner or is unused. Index 0 records the latter. It is not a native slot, and no operation adds incidences to an “unused root.” For actual i, counting misplaced labels that leave and enter gives exactly

`outgoing(i)-incoming(i)=|E_i|-|C_i|`.

Labels already at their destination contribute to neither side. The same counting identity holds for the complementary unused-label sets. It uses one actual assignment, so capacity is not separately allocated to different witness obligations.

The three direct exchange types are sound. An unused label can be added to its actual destination without duplication. A label whose destination is unused can be removed only from a donor with strict surplus above its original floor. An actual-to-actual transfer first adds to the destination, then deletes from the surplus donor. Disjointness makes the addition genuine, and donor surplus makes the deletion legal. All other roots are unchanged. The resulting boundary is again disjoint. Donor surplus need not be measured relative to its destination cardinality: correctness of the label and finite descent are sufficient.

In the blocked case `D>0`, no arc starts at 0, and every actual vertex with outgoing arcs is floor-saturated. At such a vertex,

`incoming(i)=outgoing(i)+|C_i|-a_i >= outgoing(i)>0`.

There is an actual vertex with an outgoing arc because a misplaced label exists and 0 has no outgoing arc. Following predecessors repeatedly never reaches 0 and never stops. Every selected predecessor itself has an outgoing arc, so the same positive-incoming conclusion remains available. Finiteness gives a directed cycle wholly among actual slots. Extracting a simple cycle gives distinct source vertices and therefore distinct arc labels. There are no self arcs, so its length is between 2 and q. This remains valid if some other arcs lead to 0; such arcs do not obstruct the backwards predecessor argument.

This proves a next exchange exists whenever `D>0`. Palette/index ordering can deterministically resolve the finite arc/cycle choices. It is not an unproved assertion that a locally safe choice or a decreasing potential is enough.
