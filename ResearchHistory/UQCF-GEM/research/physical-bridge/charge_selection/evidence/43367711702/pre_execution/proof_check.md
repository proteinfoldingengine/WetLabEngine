# Analytical check: additive charge and spectral exclusion

Status: analytical proof only. No scientific code, external model calls, or GitHub writes were used. The charge premises below are **NEW**. Their identification with a native source quantity is **NOT_DERIVED**. This note makes no novelty claim.

## Supplied benchmark and new hypotheses

Let S have orthonormal basis (o,p,u,v), let Q = I - |u><u|, and require the exact reduced channel, for every input density operator,

    C(rho) = Q rho Q + rho_uu |p><p|.

The initial state is rho_S tensor tau_E tensor |0_R><0_R|. The receiver R is the supplied fixed qubit, and its supplied fixed effect is F_R = |1_R><1_R|. Neither the receiver nor its effect is changed. The fixed test pair is

    rho_A = diag(1,1,2,1)/5,
    rho_B = diag(1,1,1,2)/5.

The proposed additional assumptions are:

1. **NEW additive charge:** J_S = |u><u|, and K = J_S + H_E + F_R, with tensor identities understood.
2. **NEW exact conservation:** [U,K] = 0.
3. **NEW spectral exclusion:** spec(H_E) intersect (spec(H_E)+1) is empty.

For finite-dimensional E the commutator has its usual meaning. For an unbounded self-adjoint H_E, conservation must mean strong commutation with the unitary group generated by K. The result needs no stationarity, full rank, or energy-diagonality assumption on tau_E.

## The selection rule is global, so a coherent bath cannot bypass it

Put q_s = 1 for s=u and q_s=0 otherwise, and define the bath operator block

    B_(s,r;t,r') = <s,r|U|t,r'>.

Conservation gives the intertwining identity

    (H_E + q_s + r) B_(s,r;t,r')
      = B_(s,r;t,r') (H_E + q_t + r').

For finite spectra, sandwiching between bath spectral projectors P_epsilon and P_epsilon' shows that a block can be nonzero only when

    epsilon + q_s + r = epsilon' + q_t + r'.

Consequently every block whose S,R charge changes by exactly one is zero under the spectral exclusion. For a general self-adjoint bath the same conclusion follows from the spectral projection form of the intertwining identity: operators intertwining self-adjoint operators with disjoint spectra vanish.

This is a statement about complete blocks of U on the entire bath Hilbert space. It is established before restricting to supp(tau_E). No intertwining relation on a possibly non-H_E-invariant bath support is being assumed.

In particular:

* For each retained basis state a in {o,p,v}, B_(a,1;a,0) = 0.
* B_(p,0;u,0) = 0.

Bath energy gaps of size two may remain. They can connect some other total-charge sectors, but exact C excludes their wrong-system outputs on the initialized inputs. The proof does not assume that all off-diagonal S,R blocks vanish.

## Receiver theorem

For the input |a><a| with a retained, exact C gives the pure system output |a><a|. Any positive joint state with this pure system marginal is supported on |a> tensor E tensor R. Since B_(a,1;a,0)=0 globally, its R=1 population is zero. Its receiver state is exactly |0><0|.

For the input |u><u|, exact C gives the pure system output |p><p|. The joint output is therefore supported on |p> tensor E tensor R. Since B_(p,0;u,0)=0 globally, its R=0 population is zero. Its receiver state is exactly |1><1|.

This argument works for any density operator tau_E, including coherent and rank-deficient states. In particular, the argument does not infer properties of U from a thermal or full-rank ensemble.

To obtain the fixed-effect probability for every input, let M be the effective input POVM effect:

    Tr(M rho) = Tr[(I_SE tensor F_R) U(rho tensor tau_E tensor |0><0|)U^dagger].

Then 0 <= M <= I, its retained diagonal entries vanish, and its u diagonal entry is one. Positivity implies M|a> = 0 for every retained a. Hence

    M = |u><u|,
    Pr(F_R | rho) = rho_uu.

Thus every state supported on the retained subspace has a blank receiver, the u input has receiver |1>, and the supplied fixed pair has signed and absolute probability contrast

    2/5 - 1/5 = 1/5.

For inputs with coherences between u and retained states, this theorem fixes the F_R probability. It does not claim that the entire reduced receiver state is diagonal or that the entire receiver channel is uniquely fixed.

## Nonvacuity and bandwidth

Define W_R to swap |u,0_R> and |p,1_R> and fix their orthogonal complement, acting trivially on E. The swapped vectors both have J_S+F_R charge one, so W_R commutes with K for every H_E. On the initialized R=0 subspace,

    |a,0_R> -> |a,0_R> for a in {o,p,v},
    |u,0_R> -> |p,1_R>.

Tracing E,R gives exactly C for all input operators, hence for all input states. This is a witness for every bath state tau_E and every bath Hamiltonian, including all spectrally excluded ones.

Bandwidth(H_E)<1 is sufficient for the spectral exclusion. It is not necessary: spec(H_E)={0,2} has bandwidth two and no unit gap. Conversely, spectral exclusion is not necessary for every individual implementation: W_R retains contrast 1/5 even if H_E has unit gaps. The theorem supplies a sufficient class-wide restriction.

## Exact controls showing the role of the new premises

### Drop spectral exclusion while keeping conservation

Take E to be a qubit with H_E=|1_E><1_E|, and define

    U = SWAP_(E,R) W_R.

W_R conserves J_S+F_R. SWAP_(E,R) conserves H_E+F_R because these two qubit charges have identical spectra and conventions. Therefore U conserves K. The bath spectrum {0,1} violates spectral exclusion.

For any bath state tau_E, including a coherent state, first W_R writes the source record into R; swapping E,R then leaves

    final joint state = [the former S,R state, now on S,E] tensor tau_R.

The exact source channel is still C for every input. The entire final receiver state is tau_R, independent of the source input. Thus the fixed-effect contrast is zero, with probability <1|tau_E|1> on both benchmark inputs. This control gives complete receiver blindness, not just blindness of the fixed effect.

### Drop conservation while retaining spectral exclusion

Set H_E=0 and use

    U = (I_S tensor Hadamard_R) W_R,

with E untouched. A final unitary on the traced receiver preserves exact C. The bath has no unit gap. Conservation of J_S+F_R fails because the Hadamard does not commute with F_R.

For a diagonal input whose u weight is q, the receiver before the Hadamard is diag(1-q,q), and afterward it is

    [[1/2, (1-2q)/2],
     [(1-2q)/2, 1/2]].

Both supplied benchmark inputs therefore give fixed-effect probability 1/2 and contrast zero. Their full receiver states differ, so this control proves fixed-effect blindness only. For a general coherent input, the same control gives

    Pr(F_R | rho) = 1/2 - Re(rho_pu),

which need not be constant. It must not be described as a receiver channel that is blind on every input.

These examples show failure of the universal contrast guarantee when a premise is removed. They do not show that either new premise is individually necessary for every implementation.

## Native/equal-source-charge admission obstruction

The supplied native total grade acts as the identity on the normalized source space. Its identification with J_S=|u><u| is therefore **NOT_DERIVED** and cannot be inferred from the exact channel. Replacing J_S by I_S is not an innocuous normalization: it removes the charge drop on u -> p that drives the preceding theorem.

More generally, let a diagonal source charge have q_u=q_p. Retain exact C, additive conservation of this source charge plus H_E plus F_R, and the no-unit-gap bath condition. Every basis input has an exact source output with the same source charge as its input. The R=0 -> R=1 output block then needs a bath shift of one and is globally zero. Consequently

    receiver = |0><0| for every source input.

For a finite bath of dimension d and tau_E of rank k, this blank-receiver condition also imposes the necessary dimension inequality

    2k <= d.

Proof: let rho_star=(|p><p|+|u><u|)/2. The initialized total state has rank 2k. Unitary evolution preserves that rank. Exact C gives pure system output |p><p|, and the selection rule gives pure receiver output |0><0|. Thus the output is |p><p| tensor sigma_E tensor |0><0| and has rank at most d. Equivalently, unitarity must place the two orthogonal k-dimensional input sectors p tensor supp(tau_E) and u tensor supp(tau_E) into the same d-dimensional output sector p tensor E tensor |0_R>.

For a full-rank finite bath k=d>0, the inequality is impossible. This exact-channel implementation class is empty. It cannot furnish a native detection theorem.

For rank-deficient baths the inequality is necessary but is not sufficient for arbitrary H_E. Example: d=2, H_E=diag(0,1/2), tau_E=|0><0|. This has no unit gap and 2k=d. Nevertheless p tensor |0_E> and u tensor |0_E> have the same conserved charge and would both have to map into the single vector p tensor |0_E> with R blank. Conservation prevents using the other bath energy, so unitarity makes exact C impossible. Spectral multiplicity creates an additional obstruction.

The native/equal-charge class can be nonempty for a rank-deficient bath with appropriate degeneracy. Take d=2, H_E=0, tau_E=|0_E><0_E|, leave R untouched, and swap |u,0_E> with |p,1_E>. When q_u=q_p this swap conserves the total charge, implements exact C for all inputs, and leaves R blank. This example is a witness only for this degenerate Hamiltonian, not a sufficiency claim for arbitrary bath spectra.

## Scope of the conclusion

The proposed theorem is valid as a **NEW sufficient physical-assumption result** with the supplied fixed R, fixed F_R, exact C, and fixed diagonal pair. It avoids a full-rank or stationary-bath premise. Its clean proof relies on global charge blocks, not bath-support invariance. The required binary source charge, receiver charge assignment, exact conservation, and spectral exclusion are additional physical assumptions. A native identification of that binary source charge remains **NOT_DERIVED**. With the supplied native/equal-charge observable, the same spectral condition instead gives a blank receiver and, for a full-rank finite bath, an empty exact-channel class.
