where U={u_1,...,u_m}, equals zero under source zero and one under source one. Identity gives zero under both. These are inherited facts; they are not recounted as new discoveries.

Test the following specific receiver interface. Fix a source-independent set C of indices not containing a. Grant the receiver the tuple (Z_i) for i in C, the common T,K and reference data, and local memory whose initial law is the same under both sources. Its processing rule is the same in both cases and reads only those inputs. This is a deliberately stated candidate interface, not a claim that every native observer is an indexed view or that such access has already been physically earned.

## 2. Exact receiver conclusion

For every permitted output and every i different from a,

    Z_i = Y_i^0 = Y_i^1.

Proof: every nonroot tip of Y_i is a global leaf of T. Such a tip has no strict descendant in K subseteq T. The inherited mandatory hull therefore contains every tip and its ancestors, so B_K(Y_i)=Y_i. The output bounds force equality. The source construction makes these initial non-a views equal. QED.

Consequently the pooled tuple (Z_i) for i in C is the SAME tuple under both sources, independently of which permitted output occurs. This holds even if the choices of outputs are stochastic, correlated between indices, or depend on the source: the receiver tuple is constant over the entire output class.

Any fixed receiver processing kernel on this tuple and source-independent reference/local-memory inputs therefore has the same output law in the two cases. The total variation distance of those laws is exactly zero. Under an equal-prior discrimination convention the best success probability based on this interface is one half. These are exact consequences of identical data, not measured probabilities or a derived event law.

The conclusion includes genuine activity. Source zero can perform its allowed deletion of a at v; source one can perform its allowed deletion of a at any u_j. The two internal R values differ, yet the complete pooled non-a views coincide. The failure of this receiver candidate does not depend on identity, absent events, uncertain completion, or a missing separate receipt register.

This does not erase the existing internal distinction. It identifies the channel on which that distinction is absent.

## 3. Ordered repetition does not repair this interface

Keep the same T, K, indices and references. Permit any finite sequence of contractions satisfying the same mandatory-output bounds at each step, without additions. Every non-a view remains its initial value by induction: it begins fixed by B_K, the next permitted output is identical, and the same argument applies again.

Thus repeated snapshots of a non-a view contain no new source information at any fixed finite number of queries, and a coalition of such views does not help. Source-independent adaptive processing of these identical answers also cannot distinguish the sources. This statement does not grant an executable query protocol; it characterizes its answers if that protocol is supplied.

Source-dependent transcript length, notification arrival, step counts, availability or stopping signals are separate inputs. The conclusion does not cover a receiver granted those signals. Nor does it establish preservation of a C3 band over repeated steps: the first-response report explicitly exhibits multi-step departures from the unit band. Any additional band restriction can only reduce the tested output family; it does not change the unchanged-view conclusion for remaining outputs.

## 4. Positive control and boundary of the result

The inherited interface reading Z_a restricted to U gives R immediately. Under proper outcomes it separates the two sources. Hence the result is not a general prohibition on information transfer within the same mathematical carrier. It rejects only the proposal that unchanged non-a membership data already provide that readout.

A receiver that accesses full supports at shared vertices would receive additional information: those supports include a-membership, which changes at u_j in source one. Such access must be justified rather than inferred from the receiver's own presence at that vertex. Likewise an internal component of the a-view could be a receiver if its coupling and access are derived. The proof does not require all receivers to be separate palette indices or forbid internal physical subsystems.

The complete a-view already distinguishes the source preparations before the action. Thus granting a receiver that whole initial view would change the acquisition question. The existing restricted record on U starts identical and changes under a proper source-one response; it remains a valid conditional target for a separately justified access mechanism.

The action class is essential. Bare actual carrier safety is weaker than the universal independent-view safety contract, as the inherited source-one leaf-deletion control demonstrates. Richer ownership information, joint operations, additions, changing carriers and event-mediated access may define other classes. None is excluded or silently adopted by this assessment.
