## 1. Concrete purpose and admission

The current EB target asks whether one actual event is an inherited L3/L6 pruning. The existing forward construction takes Y and computes P_XY. This note works in the reverse direction: given an event's exact lost-distinction subspace K on the already declared native grade object, reconstruct Y if possible, then determine exactly what this establishes about the event's output.

The missing correspondence attempted here is the choice of retained carrier. The positive result is that, in the stated linear diagnostic, K can fix Y uniquely without a chosen mask. The limitation is equally explicit: no inspected actual event supplies the required K on this grade object, and a loss kernel alone does not identify the physical output or receiver.

This is an elementary inverse use of FCV P1/P2 and v16.23 O3, not a new physical principle or a mathematical novelty claim. It does not reopen T-013's supplied RAS boundary, T-062--T-069's representative-choice problem, or T-156's access correction.

## 3. Positive reconstruction

Define the parent--child distinction

    d_v = e_v - e_par(v),  v != o.

For the supplied K define

    D(K) = {v != o : d_v belongs to K},
    Y(K) = X minus D(K).

Call D downward closed when v in D implies every descendant of v in X is also in D.

**Theorem 1 (exact inverse recognition).** There is an admissible retained carrier Y such that K = ker P_XY if and only if BOTH:

    (A) K = span_Q {d_v : v in D(K)};
    (B) D(K) is downward closed.

If these conditions hold, Y is unique and equals Y(K). In particular K contains no total-grade direction. Testing only which d_v lie in K is insufficient unless (A) is also checked.

**Proof.**

1. The vectors e_o and all d_v form a basis of F_X. Indeed

       e_v = e_o + sum_{w on the path (o,v]} d_w.

   There are |X| vectors and they span. Consequently the d_v form a basis of the balanced subspace sum x_v = 0.

2. For any admissible Y, if v is removed then all its descendants are removed, and v and par(v) have the same longest retained prefix. Therefore P_XY d_v = 0. If v is retained, its parent is retained and

       P_XY d_v = e_v - e_par(v) != 0.

   Thus D(ker P_XY) = X minus Y.

3. P_XY is onto by P I = id, so its kernel has dimension |X|-|Y|. The |X|-|Y| independent d_v with v removed lie in that kernel by step 2. They therefore span it. This proves necessity of (A); prefix closure proves (B).

4. Conversely, if (B) holds, Y(K) contains o and is prefix closed: a removed ancestor would force its descendant removed. It is therefore admissible. Apply step 3 to this Y. Condition (A) gives K = ker P_XY.

5. Step 2 recovers every removed vertex from K, so no different admissible carrier has this kernel. QED.

The case K=0 gives Y=X. The case K equal to the full balanced subspace gives Y={o}. A root-only X is included. Signed differences are diagnostic comparisons of source preparations, not negative physical matter.

## 4. What the event quotient determines

Assume Theorem 1 passes. Define

    Phi : F_X/K -> F_Y,   Phi([x]) = P_XY x.

**Corollary 2.** Phi is a well-defined linear isomorphism. Its retained basis is [e_y], y in Y. Every source class satisfies

    [e_v] = [e_r_XY(v)].

**Proof.** Equality of kernels gives well-definedness and injectivity; P I = id gives surjectivity. Telescope the d_w on the discarded part of v's ancestral path to obtain the class identity. QED.

Thus an event quotient with this exact K has a canonical retained-grade description relative to the inherited source addresses and retained inclusion. This is a mathematical description of the quotient, not a physical relocation assertion.

For a specified linear event map T:F_X -> V with ker T=K, there is a unique linear isomorphism

    A:F_Y -> im(T),    A = T I_YX,
    T = A P_XY.

Indeed x-I P x lies in K, so T x = T I P x. If A y=0 then I y is in K, hence y=P I y=0; every T x is in the image of A.

**Corollary 3 (calibrated output).** If the actual codomain is already independently identified with F_Y and T I_YX = id_FY, then T=P_XY. Without that retained-source identification/calibration, only T=A P is established. A is derived from T, but its identification with a particular physical receiver interface is not.

This explicitly preserves the distinction between a quotient and its physical implementation. It does not substitute P2's comparison section for physical enactment.

## 5. One explicit source--event--retained-factor construction

Take X={o,p,u,v}, with o<p<u and v another child of o. Let the event diagnostic have

    K = span{e_u-e_p}.

Then D(K)={u}, Y={o,p,v}, and Corollary 2 gives

    [e_u]=[e_p],   [e_v] distinct from [e_p].

For the declared balanced pair x^(0)=e_u, x^(1)=e_v:

- total grade is one in both preparations;
- the initial p singleton coordinate is zero in both;
- their canonical quotient coordinates are e_p and e_v;

Unlike choosing Y first, this construction obtains Y from K. It neither derives the event's K nor removes the receiver-access premise. C_p already distinguishes these particular preparations before the event; assigning access to C_p would invalidate initial blindness. ## 6. Exact adverse controls

These hand-derived controls are part of the analytical argument, not a numerical campaign.

**C1: edge membership does not certify the whole kernel.** On X={o,a,b}, K=span{e_a-e_b}. No d_a=e_a-e_o or d_b=e_b-e_o lies in K, so D(K) is empty. Condition (A) fails. The event that identifies the two siblings preserves total grade but is not any admissible ancestral P1 contraction on this X. Returning Y=X after edge-membership tests alone would be wrong.

**C2: an edge-generated kernel can violate prefix retention.** On o<p<u, take K=span{e_p-e_o}. Condition (A) holds, but D(K)={p} is not downward closed because u survives. The proposed Y={o,u} is not prefix closed. This can describe another quotient; it is outside this inherited P1 class, not impossible physics.

**C3: identical loss, different physical output labels.** On o<p<u, let P(x_o,x_p,x_u)=(x_o,x_p+x_u). Let S swap the two output coordinates and T=S P. Both P and T are nonnegative, total-preserving linear maps and have exactly K=span{e_u-e_p}. But

    P e_u=e_p,   T e_u=e_o

when the output coordinates are independently labelled (o,p). T I=S, not id. Thus even exact loss data, positivity and total conservation do not fix which physically labelled output receives the source. Corollary 3's calibration cannot be omitted. If S is merely a coordinate relabeling, this is the same abstract quotient; that is precisely why quotient identification alone is not a physical receiver assignment.

**C4: no finite preparation sample establishes exact K.** A measured or computed collision on a few source pairs does not determine the universal kernel of an actual operation, and a nonlinear/stochastic event need not have a linear loss kernel at all. No such event class is excluded from the program by this theorem.
