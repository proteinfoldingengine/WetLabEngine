# Native successor selection: rejected symmetry shortcut

Date: 2026-10-11. Inspected parent: d65eea3a2d3ea3984313520f8db1149c4cc0cba5.
Status: REJECTED AS AN OBSTRUCTION TO THE PUBLISHED ORDERED CARRIER. No scientific campaign, new physical mechanism, or closure claim.

## Proposed argument

Consider four indexed supports S_i=B_i, where B_1,...,B_4 are pairwise disjoint k-element blocks, k>=2, partitioning the existing palette. Give every root original floor k and require 3<=tau<=4. The source has tau=4. Every deletion violates a floor. Adding any label from another block to a root is admitted: it lets one label hit that root and the donating block, while the other two disjoint blocks still require separate hits, so the successor has tau=3. There are 12k such additions. These are deductive counts, not numerical verification results.

If the selector receives only indexed supports/floors and equality-only labels, within-block permutations fix the source, and for each single-addition successor some such permutation moves it. Equivariance would require a deterministic selected successor to be fixed by all these automorphisms. No nontrivial atomic successor is fixed. If NOOP is admitted it is fixed. This is a valid elementary stabilizer argument for that reduced input; it is not a universal obstruction to relational dynamics.

## Decisive scope failure

The actual COUPLED_C3_STAR_CARRIER_SCOPE.md explicitly supplies a finite ORDERED palette and indexed roots. A nontrivial permutation within a block does not preserve that full ordered input. The proposed stabilizer argument therefore cannot be applied to the published ordered carrier unchanged.

For example, order syntactic commands by the supplied root order, palette order and a fixed sign convention. For any state with a nonempty set of admitted moves, choosing its least admitted command defines a mathematical selector. Under transport of the complete ordered structure the choice transports with it. In the four-block source, even a direct prescribed choice of the least label in B_2 added to root1 gives a legal move without needing a general full-state search. This refutes the proposed impossibility of deterministic selection for the supplied ordered carrier.

Neither construction is a derived physical update law. A general least-legal-command evaluator may use information an observer lacks, and an order available to a mathematical verifier is not automatically a physical reference or actuator. The source scope already says root/child indices are supplied mathematical identities, not an earned physical observer reference. The correct unresolved question is how the relevant order/reference and an actual executing interaction arise, rather than asserting that no ordered selector can exist.

Conversely, the mathematical existence of an ordered selector does not require us to adopt it as dynamics. Other selectors can choose different admitted successors. We have not derived a law selecting among them, a probability measure, actual outcomes, recording or progress. We have also not proved that every possible native mechanism needs a total label order: a derived history, reference relation, other asymmetry, or a differently scoped dynamics could change the input and must be assessed in its own right.

## Decision

Reject the proposed symmetry shortcut as a physical-closure campaign. Preserve the reduced-input lemma only as an explanatory caveat: an equivariant single-event selector needs a fixed admissible event under the automorphisms of its COMPLETE input. Do not omit order, addresses, provenance or history when computing those automorphisms. An orbit-valued output or invariant probability distribution is a different object from a selected actual event. Synchronous multi-incidence updates are also outside the atomic-move claim.

No numerical enumeration, Actions run or Gemini request was justified. No new test count is claimed. The separate adversarial Codex review is preserved in COUPLED_C3_NATIVE_SELECTION_ATTEMPT_REVIEW.md; it is not a scientific certification. Existing mathematical checkpoints are not reopened. Native event production, record origin/access, enforcement, selection, progress and broad C3/C4-C6 remain OPEN.
