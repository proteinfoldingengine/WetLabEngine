## Result

The V725 observable-only program and the V737 reproduction program contain a concrete implemented parameter-to-response chain. Each selects high/low k, evolves an initially identical visible field using a k-dependent law, and computes a scalar from the supplied target and trajectory. The absence of a direct numerical k term from the candidate scalar does not remove the explicitly supplied k dependence of the generating dynamics.

For V725, the exact common-state, real-arithmetic first-step difference is

`Delta k [(t-x) + .06 Lx - .015 tanh(Lx)]`.

For V737, using the common standardized Gaussian draw z, it is

`Delta k [-.20(x-t) - .030 L0 x - .005 z]`.

The endpoint stencils differ, and these identities cannot be used unchanged for later diverged trajectories. V725 shares its additive noise schedule. V737 shares a seed but scales its noise by `.012-.005k`; its additive noise vectors therefore differ between unequal-k arms. This is a supplied stochastic response mechanism, not direct k insertion into the scalar and not inherently an invalid experiment.

The visible initial field is identical within each pair, while the model parameter differs. This neither establishes complete physical receiver blindness nor identifies a native owner. The scripts do not read a native event/pruning record, derive the chosen update from such a record, bind its affected field to an independently identified retained owner, or derive the owner's access to target and trajectory. The first missing correspondence includes the operation and owner/access relation; deriving k alone is not sufficient.

V725 additionally uses label-zero/high-capacity calibration for adm_z and dataset normalization. V737 removes that calibration path and direct k from its scalar, while retaining supplied dynamics and target/trajectory inputs. The two programs differ in update, noise, boundary conventions and metric, so the inspected V737 is not an exact trajectory replay of the inspected V725. None of these statements claims that a legitimate synthetic calibration or qualitative robustness experiment is invalid.

A separate static implementation caveat is preserved: V725's AUC routine adds strict-greater wins and half of an approximate-equality predicate. A strictly greater, approximately equal pair contributes 1.5 because the predicates overlap. V737 instead uses strict greater-than and exact equality. No data replay determined whether this overlap affected historical samples or any published AUC. No historical source was edited or corrected, and no new metric calculation is certified.
