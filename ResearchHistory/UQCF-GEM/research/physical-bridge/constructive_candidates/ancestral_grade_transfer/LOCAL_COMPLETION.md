### Elementary pruning determines the parent increment

Let K be a finite prefix tree, ell a nonroot leaf, and p its parent. Set K'=K minus {ell}. The inherited longest-prefix retraction fixes every retained address and sends only ell to p. Thus its extensive-grade pushforward necessarily has

    mu'(p) = mu(p) + mu(ell),
    mu'(x) = mu(x) for every x in K' other than p.

This is a specialization of the already-earned fiber sum, not a newly selected gate or response coefficient. On a fixed display carrier K, zero-extending mu' gives grade difference +mu(ell) at p, -mu(ell) at ell, and zero elsewhere. Zero extension here compares states; it is not a second physical operation.

For any prefix-closed retained Y subseteq X, remove X minus Y in child-before-parent order. Such an order exists because no retained vertex can descend from a discarded vertex. At each deletion the discarded vertex is a leaf of the then-current carrier, so the elementary formula applies. By the inherited composition identity, every such factorization yields P_XY mu. The ordering is a proof witness, not a scheduler or clock.

### The corresponding edge flow is unique

For the following accounting statement, use real nonnegative grades as in the working construction. Orient each edge upward, child x to parent p(x). Let Desc_X(x) include x and all its descendants. Define

    F_x = sum_{z in Desc_X(x)} mu(z)    if x is not retained in Y,
    F_x = 0                            if x is retained in Y.

For the root set F_o=0. Let nu be P_XY mu, zero-extended to X, and Delta=nu-mu. Then, at every vertex x,

    Delta(x) = sum_{y child of x} F_y - F_x.

At a discarded x all its descendants are discarded, so the right side equals -mu(x), which is Delta(x). At a retained x, each discarded child contributes its entire removed descendant subtree, while retained children contribute zero across their edge. These are exactly the additional atoms in x's retraction fiber, giving the pushforward increment. This also proves the root case.

Uniqueness uses only tree incidence. Sum this balance identity over Desc_X(x). Internal edge terms cancel and the only outgoing boundary term is -F_x. Hence

    F_x = -sum_{z in Desc_X(x)} Delta(z).

Every edge value is therefore fixed by the state difference. No cycle current, metric, conductance, minimization, calibration or propagation rate is selected. F is an amount aggregated over the algebraic transition, not a time-dependent flux or an additional physical variable.
