**Conventions.** A tree on n addresses is a parent array with parent[0] = none and parent[i] < i (increasing labelling; every rooted shape occurs). Genesis o = 0, depth(0) = 0. A *carrier* of a tree U is a prefix-closed subset containing 0. A single pruning removes a leaf l ≠ 0 of a carrier X, Y = X \ {l}, p = par(l), and acts by P1: (Px)_p = x_p + x_l, other retained coordinates unchanged. A *cover* is a pair X ⊂ X' = X ∪ {w} of carriers. C_a^X(x) = sum over v ∈ X with a ≤ v of x_v. An assignment gives a matrix M^X (rows v, columns u, both in increasing address order) per carrier, ω_v^X(x) = sum_u M^X_{vu} x_u. For a function b on non-Genesis addresses, a(u) = 1 - sum over o < w ≤ u of b(w) (a(0) = 1) and the *family matrix* M(b)^X is (17.1): M_{vv} = a(v), M_{vu} = b(c_v(u)) for v < u (c_v(u) the child of v on the path to u), 0 otherwise. Fractions are written in lowest terms "a/b", integers "a"; vectors are lists of such strings. The *one-location pair* at l is x versus x + w e_l; its *before* and *after* differences are ω_p^X(w e_l) and ω_p^Y(P w e_l); it is an *acquisition* iff before = 0 and after ≠ 0. The *correlated pair* (GPT `5cd3c6d5` section 3) at a pruning with p ≠ 0 and D = a(l) > 0: r = b(l)/a(p), z = the all-ones vector on X, v* = the smallest address of X \ {0} that is not in the closed subtree of p if one exists, else 0; x_plus = z + e_l, x_minus = z + r e_p + (1 - r) e_{v*}.

**Assignment panel** (defined on every tree; b given on non-Genesis addresses w, depth(w) its depth):
- `own`: b ≡ 0 (I*-b).
- `gtax` (Control 17.5(a)): b(w) = 1/2 if depth(w) = 1, else 0.
- `half`: b(w) = 1/4 for every w ≠ 0.
- `deep`: b(w) = 1/3 if depth(w) = 2, else 0.
- `sat`: b(1) = 1, b(w) = 0 for w ≠ 1 (so a(1) = 0 and a(u) = 0 for every u in the subtree of 1).
- `mixed`: b(w) = ((3w + 1) mod 5)/20.
- `negative` (sign control): b(w) = 1 if depth(w) ≤ 2, else 0 (so a(u) < 0 at depth ≥ 2); the matrices M(b) are used without the sign condition.
- `cone` (Control 17.5(b)): ω_v^X = C_v^X.
- `parent` (Control 17.5(c)): ω_v^X(x) = [v = 0] x_0 + sum over children w of v in X of x_w.
The first seven are *affine* (of the form M(b) for some b); the first six are *family* members (b ≥ 0, a ≥ 0 on the universe).

**Condition tests** (each a boolean per assignment and universe, evaluated over every carrier, cover and single pruning): W1eq = every column of M^X sums to 1; W1pos = every entry ≥ 0; W2 = on every cover X ⊂ X', M^{X'}_{vu} = M^X_{vu} for v, u ∈ X and M^{X'}_{wu} = 0 for u ∈ X; W4 = for every single pruning, ω_v^Y(Px) = ω_v^X(x) as functionals for every v ∈ Y \ {p}; family / affine = the assignment equals M(b) for the b recovered by b(u) = M^{[0,u]}_{par(u), u} (with b ≥ 0, a ≥ 0 for family); L170 = M^X_{vu} = M^{[0,u]}_{vu} for all X ∋ u, and = 0 unless v ≤ u; (i) = M^X is the identity on every carrier; (ii) = the one-location pair is an acquisition at every single pruning of the universe; (iii) = M^X_{par(l), l} = 0 for every single pruning; (iv) = the receiver increment functional ω_p^Y(P·) - ω_p^X(·) equals e_l^* (coefficient 1 on x_l, 0 elsewhere) at every single pruning; D = M^X_{vu} = 0 for every carrier and every strict descendant u of v.
