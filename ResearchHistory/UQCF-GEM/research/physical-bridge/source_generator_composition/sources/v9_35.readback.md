## 1. Native source expectations

Let

\[
\mathcal H=\bigotimes_{i=1}^{N}\mathcal H_i
\]

and let \(Q_i\) be a distinguished source observable acting only on factor \(i\), with spectral projectors \(P^{(i)}_a\). Define

\[
\Delta_i(X)=\sum_aP^{(i)}_aXP^{(i)}_a.
\]

Each \(\Delta_i\) is trace preserving, completely positive, unital, self-adjoint in the Hilbert–Schmidt metric, and idempotent.

## 2. Exact composition theorem

For \(i\ne j\), every \(P^{(i)}_a\) commutes with every \(P^{(j)}_b\). Therefore

\[
\boxed{\Delta_i\Delta_j=\Delta_j\Delta_i.}
\]

For a subset \(S\subseteq\{1,\ldots,N\}\), define

\[
\Delta_S=\prod_{i\in S}\Delta_i.
\]

The product is independent of factor ordering and obeys

\[
\boxed{
\Delta_S\Delta_T=\Delta_{S\cup T}.
}
\]

Consequently the native source-reduction channels form a commutative idempotent semigroup isomorphic, when all local spectral splits are nontrivial, to the Boolean join-semilattice of subsets.

This is a genuine irreversible reduction structure. It does not select a maximal chain through that structure.

## 3. Selective branch theorem

For outcomes \(a_S=(a_i)_{i\in S}\), define the joint projector

\[
P_{a_S}=\prod_{i\in S}P^{(i)}_{a_i}.
\]

Every sequential ordering of the corresponding Lüders outcomes gives the same unnormalized branch state

\[
P_{a_S}\rho P_{a_S}
\]

and the same joint probability

\[
p(a_S)=\operatorname{Tr}(P_{a_S}\rho).
\]

Conditional probabilities can be factorized in different written orders, but all factorizations represent the same joint law. Neither selective nor nonselective native source reduction contains an intrinsic ordering observable.

## 4. Pure-state entropy theorem

For a pure state \(|\Psi\rangle\), decompose it into the orthogonal source sectors

\[
|\Psi\rangle=\sum_{a_S}|\Psi_{a_S}\rangle,
\qquad
|\Psi_{a_S}\rangle=P_{a_S}|\Psi\rangle,
\qquad
p(a_S)=\lVert\Psi_{a_S}\rVert^2.
\]

Then

\[
\Delta_S(|\Psi\rangle\langle\Psi|)
=\sum_{a_S}|\Psi_{a_S}\rangle\langle\Psi_{a_S}|,
\]

whose nonzero eigenvalues are exactly \(p(a_S)\). Hence

\[
\boxed{
S\!\left(\Delta_S(|\Psi\rangle\langle\Psi|)\right)=H(A_S)
}
\]

and

\[
\boxed{
\operatorname{Tr}\!\left[\Delta_S(|\Psi\rangle\langle\Psi|)^2\right]
=\sum_{a_S}p(a_S)^2.
}
\]

Along any chosen permutation \(\pi\), the entropy increments satisfy the classical chain rule

\[
H(A_{\pi_1},\ldots,A_{\pi_N})
=\sum_{k=1}^{N}H(A_{\pi_k}\mid A_{\pi_1},\ldots,A_{\pi_{k-1}}).
\]

The increments depend on the chosen factorization, but their sum and the final state do not. The chain rule evaluates a supplied order; it does not select one.

Therefore all joint moments and the complete joint outcome distribution of the \(Q_i\) are invariant under every nonselective native source dephasing.

Any proposed next-event rule depending only on those source values is not self-updating: after one event, the same source-coordinate data remain. It cannot derive a unique next source.

## 6. Symmetric-state obstruction

At a state and source family invariant under a transitive permutation of eligible factors, covariance requires a deterministic first-event choice to be fixed by that permutation stabilizer. No individual source is fixed. Thus no universal deterministic covariant first-source selector exists on the symmetric stratum.

Simultaneously applying every \(\Delta_i\) is covariant, but it is a one-shot idempotent map. Reapplying it changes nothing and therefore cannot generate an extended sequence.

## 7. Noncommuting control

Order sensitivity is mathematically possible if two selected observable algebras do not commute. For a qubit, dephasing about Bloch axes \(n\) and \(m\) acts as

\[
r\longmapsto(n\cdot r)n,
\qquad
r\longmapsto(m\cdot r)m.
\]

Thus

\[
\Delta_n\Delta_m(r)=(m\cdot r)(n\cdot m)n,
\]

while

\[
\Delta_m\Delta_n(r)=(n\cdot r)(n\cdot m)m.
\]

These generally differ. But order dependence alone does not select an order, and the frozen native source observables act on distinct factors and commute. Introducing a noncommuting relational measurement family would be additional structure whose extraction and succession law must be independently derived.
