# Buffered cyclic composition with core loop erasure

Status: proposed analytical theorem; verification/review pending.

## Native objects and supplied interface
Use the pool/background/floor/guarded-current-core objects of the reactive handoff theorem. There are k distinct active labels A_i on nonempty patterns W_i covering all nonhost roots, and two distinct hosted labels D,E. Hidden fixed Q is disjoint from pool and fresh w. Positive floors do not exceed source sizes;3<=tau(source)<=4. The current core projection contains all pool incidences but excludes w and Q. No other writers or delayed edits occur. Orders, addressing, source template and prescribed goal are supplied static data.

Choose a prescribed chain of ell>=1 DISTINCT role slots, renamed1..ell in visit order; unvisited slots remain fixed. For each visited W_j, a set K_j of at most two other stable role slots covers all nonhost roots outside W_j. Let P_j be W_j covered by those roles and R_j its deficit, r_j=|R_j|, m_j=|W_j|. Slot certificates depend on patterns; their labels change according to completed chain visits. The entering label is D for j=1 and A_(j-1) thereafter. The departing label is A_j. No marker/core/floor/tau/background read beyond the supplied core interface is added.

## Why independent macro composition can cycle
Finish the nonhost exchange of a macro and call its state X, with departing A absent everywhere, hosted E,w and the new core role complete. Adding A at h produces Y. Using A as incoming label for the next macro starts by removing A from h, returning EXACTLY to X if w is retained. Both changes are legal by the one-handoff proof. Thus any state-only set-valued policy that faithfully retains both segment actions contains X->Y->X. Even full-state observation cannot distinguish the two occurrences of X. No strictly increasing state rank can certify that union graph.

This refutes faithful memoryless composition of those host-parking segments, not all possible repair protocols or controllers. Cleaning and re-adding w between macros does not derive a phase record either. The single-macro theorem remains valid; its policy was not claimed composable.

## One buffer, no internal parking
Prepare +w(h),-D(h) only once. At each j execute the deficit nonhost script: exchange each covered root by adding the entering label then deleting A_j; add entering at all R_j, then remove A_j at all R_j. After that, A_j is absent everywhere and is available to enter W_(j+1) directly. Do not park it at h between visits. End with +A_ell(h),-w(h).

The exact goal is D on W_1, A_(j-1) on W_j for2<=j<=ell, A_ell at h with E, and all unvisited roles/Q unchanged. One marker suffices for the entire chain. The raw nonhost script has N=2 sum_j m_j changes.

Floors: each nonhost slot exchange adds before deleting and never drops below its original size; at visit boundaries the same role patterns are occupied by distinct labels, so sizes equal source sizes. Throughout the pipeline host E,w,Q has original size. Initial marker preparation and final host restoration/removal are safe. If the host floor has one unit of slack, direct -D without w is also safe; its host remains one below original until final +A_ell. The controller never needs to read that floor value.

Lower bound: during a visit map every completed incoming slot label to that slot's original A_i; map all untouched active labels to themselves. When an entering label first appears on W_j map it to original A_j. It was absent everywhere before that addition, so this does not conflict with an earlier slot. The departing A_j continues to map to itself until it disappears. Map w->E. At final host addition map A_ell->original D; A_ell is then absent from all nonhost roots. E, unvisited labels and Q remain fixed. Every current root support maps into its original support. Consequently every current hitting set maps to a source hitting set of no larger size, yielding tau(current)>=tau(source)>=3. The map need not be injective; it is a proof device, not an observed operation.

Upper bound during visit j: use current labels of K_j plus E and departing A_j until every deficit addition is complete, then current K_j labels plus E and entering label. The covered roots are protected by K_j and outside roots are covered by its certificate; each set has at most4 labels. Empty deficits present no difficulty. Certificates may change at visit boundaries because all core role patterns are again fully occupied. Thus all raw slices stay in3..4. A source with tau4 remains4; exact tau3 invariance is not claimed.

Peak excess is at most beta=max_j max(1,r_j): preparation/final host edit costs1, covered-root duplication costs1 and each deficit batch costs r_j. No intermediate host parking/restoration overhead accumulates. On the direct no-marker branch peak is at most max(0,beta-1). The raw chain uses N+4 marked changes, or N+2 direct changes, versus N+4ell for independent marked macros.

## Shared incidences can still make the raw core path repeat
For the bounded b4,c3,z0 source, role0 has W0={0,1,2}, role1 W1={2,3}, role2 W2={0,1,4}. Both other roles cover W0. Its last exchange deletes label0 at root2; the next visit immediately adds that same label at root2. These adjacent toggles return to the same full state. A pipeline alone therefore does not justify a phase-free controller or a strict core rank. This analytical fixture was known before execution.

## Uniform loop erasure is a valid native path reduction
Let c_0,...,c_N be the raw NONHOST core slices, with D already removed from h and E the only hosted pool label. Apply chronological loop erasure: whenever the next slice equals an earlier retained slice, remove the intervening closed walk; otherwise append the slice/edge. This preserves original edge identities, giving a core-simple path d_0,...,d_L, L<=N. Every retained transition is one of the original addressed toggles, and the exact first/last core slices are preserved.

Why the deletion is valid across every promised hidden world: w is constant throughout these nonhost slices (either always present at h or always absent on the slack branch), Q is fixed, and all non-pool data is unchanged. Equality of cores at two raw slices therefore means equality of the FULL carrier state in each such world. Splicing the following original transition at that identical state preserves syntactic validity, floors and hitting band. The erasure depends only on the known core script, never Q, w, floors or tau. Thus it works uniformly for every promised background/floor source, and deleting slices cannot increase peak excess. This conditional exact lifting is not a universal injectivity claim for the core channel.

No optimality follows: chronological loop erasure produces a simple path, not necessarily a shortest admissible path. Different orders can produce different paths. Computation of this static path uses supplied role templates/certificates, not a native derivation of those records.

## Phase-free policy and complete outcome graph
At the source core offer +w(h) and -D(h). At each d_t for t<L offer its uniquely retained outgoing toggle. At d_L offer +A_ell(h). At the goal core offer -w(h). Outside these templates offer nothing. The source, interior and goal cases are disjoint by host pool incidences: source hosts D,E, interiors E alone, goal A_ell,E. Interior templates are distinct after erasure. Thus the policy uses only the current core and static path, with no mutable phase, macro counter, marker read or success acknowledgment.

Under the exact inherited guarded relation, every request may NOOP; syntactically valid admissible requests additionally permit the single toggle. All marked interior d_t slices are reachable. Unmarked interiors are reachable exactly when the host floor permits direct -D. The two source-marker states share the same policy, as do the clean/marked goal pair. There are no other reachable states or changes: all interior requests are legal by the splicing proof, while source direct deletion has precisely the host-floor condition; repeated marker additions and clean-goal deletions are syntactic NOOPs.

Assign rank0/1 to unmarked/marked source,2+t to interiors d_t, L+3 to marked goal and L+4 to clean goal. Every committed change increases rank; the clean goal is the sole committed sink and is absorbing. Every maximal committed path therefore reaches the exact prescribed cyclic goal, with at most L+4<=N+4 marked changes or L+2<=N+2 direct changes. Arbitrary NOOPs and set-valued request selection can still stall indefinitely. Clean completion remains unobservable because the two goal-marker states have identical core. No deterministic scheduler, progress law, global path optimality, arbitrary macro/target composition or physical observer mechanism is derived.

## Scope of advance
The host-parking counterexample identifies a real committed cycle. The pipeline plus uniform core loop erasure removes both parking and shared-incidence cycles, allowing a prescribed DISTINCT-slot cycle to be controlled without stored macro/phase history. This is stronger than the prior single-macro theorem, still conditional on native core access, guarded enforcement, static routing/certificates, freshness and initial admissibility. Missing coverage certificates and repeated-slot/arbitrary-target cases remain outside this construction. No time primitive, inserted geometry, dark matter, force or GR derivation is asserted.
