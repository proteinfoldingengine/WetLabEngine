## 3. Declared interface and proposition

A type t specifies the carrier, common Genesis and any declared mathematical domain. A state is (t,x), with x in that domain.

Let A(t) be a set of command labels determined by t. Each a in A(t) names a total function f_a on that domain with target type t_a determined by (t,a). The core example consists of the P1 pushforwards, P2 inclusions and admissible structural relabelings, and type-correct finite compositions.

For this candidate, the visible transcript contains command labels, source/target types, eligibility answers and completion of admitted commands. It does not expose numerical coordinates, scalar tests of them, runtime/timing, or a grade-dependent outcome. We grant this structural transcript for the analysis; FCV does not thereby become a physical command/readout implementation.

**Proposition.** Any two initial states (t,x) and (t,x') have exactly the same finite eligible command words and structural transcripts in this class.

**Proof.** At length zero the type agrees. If a prefix has produced the same type t_k in both executions, the eligible next labels are the same A(t_k). For each such label a, totality supplies a successor for both states and the next type is the same t_a. The two numerical successors f_a(x_k) and f_a(x'_k) need not agree. Induction on word length proves equality of all finite eligible words and their structural transcripts. Invalid-command rejection, if included, is also the same because eligibility depends only on type. QED.

This is a direct type/trace argument, not a new proof of P1 or a claim of mathematical novelty.

**Adaptive policies.** A controller with the same initial memory, reading only this transcript and using the same source-independent policy, also has identical transcript laws. Couple its random choices in the two executions; induction gives equal choices and observations at every finite step. Hence any receiver-local projection of this transcript is equally uninformative. No native stochastic law is inferred.

Without that policy restriction, the result is only equality of possible words. A grade-dependent scheduler could assign different probabilities to the same possible words. Its source dependence and physical availability would need their own inherited justification; admissibility alone neither supplies nor excludes them.
