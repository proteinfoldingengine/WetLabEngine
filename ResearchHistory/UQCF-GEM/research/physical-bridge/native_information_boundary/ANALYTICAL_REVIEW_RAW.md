## Independent reconstruction of the mathematical result

### Precise information class

Work in one fixed concrete rooted prefix-address system with root `o`. A view is a finite, root-containing, prefix-closed set of addresses. Fix an indexed palette `P` with at least two indices and a finite root-containing prefix-closed positive-evidence set `K`. For each possible carrier `T`, the premise is `K subseteq T`; a cover is any indexed family of views `Y_i subseteq T` whose union is `T`.

Each rule has input `(i, P, K, Y_i)` and fixed supplied identity/order data, and has no further input describing `T`, other views, witness ownership, history, a protected profile, or a restricted source family. Its output must be a root-containing prefix-closed subset of `Y_i`. Complete own-view input is essential: the absence of strict descendants in that view is available mathematically only because the view is complete or an equivalent fact is separately certified.

The universal claim ranges over every finite `T` containing the fixed `K` and every such indexed cover. It is not a claim about only the observed carrier or only a selected preparation. For any local input `Y`, `Q=K union Y` is an allowed finite prefix-tree completion. Repeated views and root-only views are allowed in an indexed family; distinct indices need not carry distinct subsets.

The at-least-two-indices assumption makes every such local input reachable in a cover and supplies the other view in the necessity construction. No permutation symmetry is needed: all fixed supplied identity/order data can be retained throughout the argument. The proof does not erase an existing order to manufacture an impossibility.

### The local mandatory set

Define

`M_K(Y) = Y intersect L(K union Y)`

and

`B_K(Y) = {o} union Anc(M_K(Y))`.

For a vertex `l` in `Y`, membership in `M_K(Y)` is equivalent to both of the following: `l` is a leaf of `Y`, and `K` contains no strict descendant of `l`. If `l` had a strict descendant in either set, prefix closure would provide a child in their union. Conversely, a strict descendant in the union must come from `Y` or `K`. Thus the equivalence used in the draft is exact.

Every ancestor of a member of `M_K(Y)` lies in `Y`, so `B_K(Y)` is a root-containing prefix-closed subview of `Y`. A node can be omitted from this mandatory set only if every terminal own-view branch beneath it has positive extension evidence in `K`. Extending one terminal branch does not authorize omission of another branch or their common ancestor if an unextended terminal branch remains.

### Necessity, reconstructed independently

Fix an index `i`, an arbitrary local input `Y`, and a nonroot `l` in `M_K(Y)`. Let `T=Q=K union Y`, take `Y_i=Y`, and take every `Y_j=Q minus {l}` for `j != i`.

This is a legal indexed cover. `Q minus {l}` is root-containing and prefix-closed because `l` is a nonroot leaf of `Q`. All nodes except `l` occur in every other view, and `l` occurs in `Y_i`. Hence their union is exactly `Q`. The fact that `l` may itself belong to `K` is harmless: `K` is an assertion of membership in the carrier, not an assertion that each view must contain `K` or that a particular other view owns its witnesses.

The local input to `F_i^K` is unchanged. Every other output contracts a view that lacks `l`, and therefore cannot recover it. If `F_i^K(Y)` omitted `l`, the union would fail to cover this admissible carrier. Universal preservation consequently forces `l` into that output. Prefix closure forces all its ancestors. Root membership is mandatory by output type. Taking all such leaves yields `B_K(Y) subseteq F_i^K(Y)`.

The argument covers each `i,Y` independently; it is not restricted to inputs from one previously selected cover. If `Q` is root-only there is no nonroot leaf to isolate, and the mandatory-root condition gives the result directly.

### Sufficiency, reconstructed independently

Let an arbitrary admissible finite carrier `T` and cover `(Y_i)` be given, and assume every local output contains its corresponding `B_K(Y_i)`. Every global leaf `l` of `T` belongs to some `Y_i`. Since `K union Y_i subseteq T` and contains `l`, that union cannot contain a strict descendant of `l`; hence `l` is a leaf of `K union Y_i`. It belongs to `B_K(Y_i)` and therefore to that output.

Every node of a finite rooted tree is an ancestor of some global leaf. Output prefix closure therefore retains every node of `T` somewhere. No output contains a node outside `T`, since it contracts an input subview. The output union equals `T`.

This proves the exact iff statement, including both inclusions once the contraction output type is imposed. Applying `B_K` to every view meets the bound itself, so it is the unique componentwise least retained safe output. It is not the only safe rule.

### Quantifier and boundary challenges

- **Root-only carrier:** necessarily `K=Y_i={o}` and every output is `{o}`. Both directions hold without deleting the root.
- **Root-only local view in a larger carrier:** `B_K({o})={o}`; other views supply the rest. The theorem makes no impossible demand on this view.
- **Repeated views:** the necessity witness deliberately repeats `Q minus {l}`. This is allowed by the indexed-cover contract and by the preceding source theorem. Requiring distinct or irredundant views would change the class.
- **A leaf in `K`:** positive knowledge that the node is somewhere in the carrier does not say it is in another view. The exclusive-leaf construction remains valid.
- **Partial own-view inspection:** a list of seen nodes is not the complete `Y`. Without an earned terminal/absence fact, the event cannot infer that deleting the listed tip preserves prefix closure of its actual view. The draft states the complete-input premise expressly.
- **Extra promises:** known view ownership, a fixed carrier, a restricted source family, historical correlations, profile restrictions, or a derived joint interaction can invalidate the adversarial completion's admissibility. The theorem does not apply after those inputs are added without a new analysis.
- **Supplied order and identities:** the proof does not depend on label symmetry. An ordered rule still faces the same input at the adversarial completion. If extra order/history data encode additional carrier facts, they are additional inputs outside the declared class rather than data this theorem may silently discard.
- **Finite carriers:** the global-leaf sufficiency step uses finiteness. An infinite branch without a leaf is outside the theorem. No infinite-carrier extension is earned here.

## Atomic strict-descendant certificate

Let `v != o` be a leaf of the complete own view `Y`.

If some strict descendant `d` of `v` lies in `K`, then `d` lies in the same actual `T`. It cannot lie in `Y`, because `v` is terminal there. Coverage puts `d` in another view; prefix closure puts `v` in that other view. Deleting only `v` from the selected view while leaving the others unchanged therefore preserves the union and the selected view's prefix closure.

Conversely, suppose `K` has no strict descendant of `v`. Then `v` is a leaf of `Q=K union Y`. Taking `T=Q`, the selected view `Y`, and all other views `Q minus {v}` makes `v` exclusive to the selected view. Its deletion loses the carrier. The purported guarantee over all consistent completions fails. Membership of `v` itself in `K` does not defeat this counterexample.

Thus the iff condition is exact for this positive-evidence information class. It is not a universally necessary condition for safe deletion under a different information class: a truthful other-view ownership certificate could suffice without any strict descendant.

The distinction between an atomic update and concurrent updates is also correct. The one-deletion proof uses an unmodified covering view; it cannot alone justify a batch of arbitrary simultaneous removals. The full family theorem supplies the simultaneous guarantee when every output satisfies its mandatory-set bound. The witness need not identify which other view contains `d`, but must identify `d` in the same current carrier and address system. No historical provenance record by itself establishes that fact.

## Nondeterministic extension

Let `O_i(K,Y)` be a nonempty set of possible output subviews, and require preservation for every element of the Cartesian product of local choices, for every admissible cover.

If one possible output omitted a nonroot leaf of `K union Y` belonging to `Y`, use the same exclusive-leaf completion. Select that output for index `i` and any permitted outputs at the other indices. None of those other outputs can contain the leaf because their inputs lack it. This product choice fails. Hence every possible local output must contain `B_K(Y)`.

If every possible output contains the bound, the deterministic sufficiency proof applies to each Cartesian combination. This proves the advertised extension. The universal product requirement is doing work; it does not describe arbitrary correlated outcomes. For a joint relation, some combinations of marginally possible local outputs can be excluded, and preserving a globally coordinated survivor can be safe even when some local marginal outputs omit an otherwise mandatory leaf. The draft correctly excludes that setting from this theorem.

There is no probability measure, selected outcome, or progress assertion in this extension. It does not require deterministic physics. A separate stochastic consumer would require its own justified kernel, input scope, record/error contract and retained access.

## Information limits, idempotence, and nonselection

1. If `K={o}`, the leaves of `K union Y` are exactly the leaves of `Y`, whose ancestral hull is `Y`. Thus `B_K(Y)=Y`, recovering the old no-carrier result.
2. If `K=T` and `Y subseteq T`, then `K union Y=T`, so `B_K(Y)=H_T(Y)`, recovering the old full-carrier result. The qualification `Y subseteq T` is necessary and is present in the draft.
3. If `K_1 subseteq K_2`, every local leaf with no strict descendant in `K_2` also has no strict descendant in `K_1`. Taking ancestors proves `B_{K_2}(Y) subseteq B_{K_1}(Y)`. This compares information contracts; it is not a time evolution law.
4. Put `W=B_K(Y)`. Every nonroot leaf of `W` is one of the leaves selected from `Y intersect L(K union Y)`: an ancestral hull of finitely many leaves has no other nonroot terminal vertex. Such a leaf has no strict descendant in `K` and stays in `W`, so it is mandatory in `B_K(W)`. Its ancestors regenerate all of `W`; contraction gives the reverse inclusion. The root-only case is immediate. Therefore `B_K(B_K(Y))=B_K(Y)`.
5. Identity also lies between `B_K(Y)` and `Y` and is safe. On a local terminal node extended by `K`, identity and `B_K` can differ. Safety and the existence of a least retained output do not select the least output as an event law. Idempotence is asserted for `B_K`, not for every safe rule. No general safe-rule idempotence was proved or needed.
6. Repeating `B_K` with the same inputs/carrier yields no further pruning. Allowing new evidence or changing the carrier changes the premises and requires a new validity argument. Same-union evolution preserves `K`'s carrier membership once that evolution is independently justified; arbitrary carrier contraction does not.
