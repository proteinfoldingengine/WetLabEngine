This audit follows the reviewed [P1 work-to-connection result](P1_WORK_CONNECTION_RESULT.md). This document tests the strongest positive use of that object and locates the first unsupported correspondence.

## 1. Strongest positive correspondence candidate

The v15.39 closed-face construction is genuinely four-supported and structured. For an oriented face \(f\),

\[
\delta_f=B_2e_f,\qquad B_1\delta_f=B_1B_2e_f=0.
\]

The archived ledger verifies at \(L=5,7,9,11\) that the closed face has delta equal to the corresponding \(B_2\) column, its coarse \(q\) is null, its higher-incidence \(\kappa\) is nonzero, and the construction is additive, reversible and covariant under the tested generators. The v15.40 acquisition later uses centered face sources and its selected global-balance response to recover the periodic square neighbor relation. These facts make the B2 path a concrete candidate for the multi-address structure missing from the supplied four-corner control.

## 2. The candidate is not a P1 retained-source bridge

The same immutable evidence fixes the boundary.

1. The v15.39 ledger says source_axiom_derived_from_frozen_ontology is false, source_axiom_user_approved_before_execution is true, and uses_pruning is false.
2. The only archived map from the closed edge source to the coarse vertex channel is \(q=B_1\delta\), and for the four-supported closed-face source that value is identically zero.
3. The v15.43 acquisition imports the v15.40 response generator and response-geometry evaluator. It constructs centered_source(L,label) independently for each periodic face and does not consume an FCV P1 carrier, a P1 contraction, or a retained vertex-grade record.
4. The v15.43 published interpretation marks source correspondence NOT_EVALUATED.
5. The reviewed P1 work-to-connection proof explicitly supplies the periodic address catalog, four-corner grade preparation and label association.

Therefore the inspected code contains two distinct channels:

\[
\text{P1 retained vertex grade}\longrightarrow \text{retained work},
\]

and

\[
\text{approved face occurrence}\longrightarrow
(\delta_f,\;q=0,\;\kappa_f)\longrightarrow
\text{periodic response geometry}.
\]

No inherited operation in the inspected dependency closure maps the first channel into the second while preserving source provenance. The equality \(B_1B_2=0\) does not transfer a P1 record; it erases the closed face from the coarse vertex channel. Treating \(\kappa_f\) or the periodic face label as the P1 record would introduce precisely the event/state correspondence that remains to be derived.

This is not a no-go theorem against every possible interface. It is a source-boundary result for the inspected implementations. A new eligible route must exhibit an inherited event operation that produces a nonzero higher-incidence output from the retained P1 record, or an inherited source output already carrying both the retained vertex-grade provenance and the required multi-address relation.
