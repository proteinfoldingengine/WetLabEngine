# Post-freeze specificity check for the bracket response

The old H4 reference study tested a distinct rank-lift statistic on random vectors. Its results are not evidence about the 207 coefficient. After freezing the current review we test sensitivity of that coefficient to scrambling positions of the three inner input vectors. Perform 128 deterministic controls, fresh Python random.Random(seed) at seed 0 through 127, independent permutations for each of J2,J3,J4, keeping each vector's entries, the original outer input, all gates and the input/output coordinate labels fixed. Evaluate every seed without selection. Report counts with nonzero and with exactly +207 at input 2/output 3, plus the count of nonzero full contrast matrices. These are diagnostic counts on a constructed ensemble, without a sampling interpretation. Exact algebra already predicts that full port tomography recovers s_i from ΔJ(i,i−1)/γ when γ is known and nonzero; verify all twelve against the independent exact right operands. Also test known fixed-background input alternatives that give the same local response contrast; a port slope alone cannot determine how its background was formed. No result of this shuffle test is known here before execution. These checks are outside the frozen independent review packet.
