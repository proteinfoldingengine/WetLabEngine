# The original caller computes the route and a remote child uses it

In the original v16.48 recursive-chain campaign, changing which of two holders relinquishes the same source site selects different inputs to the same untouched subtree. The child uses the input in its own computation. Its parent takes the child's returned states and writes them back. A third holder B gains a remote site in one history and retains it through completion. The other history leaves B's complete state unchanged. The original caller computes the route from the incidence data. The two histories have the same number of primitive updates. The corresponding change of the joint unit-tree field at the remote edge is zero.
