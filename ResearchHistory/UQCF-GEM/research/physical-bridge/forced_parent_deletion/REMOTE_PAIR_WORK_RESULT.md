# Two views carry a geometric sign of a deletion in a third

An archived three-view writer produces a source-sensitive work comparison using only the memberships of the other two views. The first change in that comparison identifies the source deletion in two original executions, even with the palette order hidden. The third original execution of the same deletion leaves those two views with exactly the same history as its matched control. [Derivation and scope](REMOTE_PAIR_WORK.md)

The marked source holds leaves 2 and 3. A reference holds leaves 1 and 2, and the receiver starts blank. The writer first removes a duplicate of leaf 2. When the source makes that deletion and the writer copies its surviving leaf 3 to the receiver, the receiver moves farther from the reference in the inherited work comparison. Restoring the just-cleared bit makes the same writer copy leaf 2 first. Because the reference already holds leaf 2, the work moves down. These signs hold for every common strictly positive leaf grade. They can be read as the first change in the two-view comparison without an elapsed time or an execution-stage label. The method assumes the archive's leaf priority.
