1. Some unchanged view C contains the one added vertex h because the union was already U. Let J=Y∩C and J'=Y'∩C. Then Y∪J'=Y' and Y∩J'=J.
2. The old Y grade b and the grade P_(C,J') c have the same pushforward to J by the old compatibility and P1 composition.
3. By O2, their unique compatible common extension on Y' is
     
       b' = glue(b, P_(C,J') c).
     
   In particular P_(Y',Y) b'=b. This construction uses the existing old local grades. It needs no ambient vector as an input to the edit, and multiple unchanged holders of h give the same result. To see existence across the whole cover, the old ambient g gives a compatible candidate P_(U,Y') g, which meets those conditions and therefore equals b'.
