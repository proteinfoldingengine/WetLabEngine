## The tempting completion, and why it fails the task

Consider completing the relation by the rule:
“Whenever the requested toggle is admissible, commit it; otherwise leave the state unchanged.”

Under this rule the two requests give (d1,d2)=(x,y), preserving hidden input and producing distinct internal records. This is a mathematically consistent deterministic choice of successors in the declared relation. It is not a consequence of that relation: the unchanged successor is also explicitly permitted on each legal request.

The proposed write therefore contains an additional resolution rule. Implementing the rule by evaluating hidden floors/full supports in a verifier would also fail to derive a native enforcement mechanism or observer access. The candidate was rejected at this step; the stronger resolution rule was not adopted, and no existing model definition was modified.

This separates three claims:
- correlated internal record states are admissible and reachable: already established;
- these prescribed requests necessarily write the record: false for the inherited relation;
- a native mechanism realizes a suitable resolution and makes the record accessible: still unconstructed.

Existential reachability is not replaced by universal realization merely by calling the endpoint an observer. Conversely, rejection of this deterministic completion as a derivation does not deny the existing conditional record constructions.

## Restoration does not solve memory origin

Reinserting a and c restores this candidate's record coordinates to 00. It leaves (x,y) intact but removes the information from this chosen record subsystem. A separate retained copy would require its own justified write/retention construction. The closed core-readout theorem legitimately assumes accessible snapshots and retained history; this attempted construction cannot cite that history as an internally generated memory mechanism without supplying the missing construction.

This is not a universal information-destruction claim: the hidden input itself remains in the carrier.
