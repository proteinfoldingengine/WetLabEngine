# Exact core certification and the fixed-family preparation boundary

Status: analytical argument frozen before execution; reviews pending.

## Native domain and task
There are finitely many fixed labelled roots with known nonempty core supports C_i subset P and tau(C) in{3,4}. Positive original floors satisfy f_i<=|C_i|. Hidden palette T is disjoint from P and contains a label u; it can contain arbitrarily many others. An initially possible state is S_i=C_i union Q_i, Q_i subset T, with3<=tau(S)<=4. The information fiber contains ALL such completions; no hidden-correlation restriction or observed exact tau is supplied. Since adding incidences cannot raise tau, the upper bound follows from tau(C)<=4. Empty Q is a valid completion.

Choose a fixed NONEMPTY labelled family F of roots and let B be its complement. Define p(S)=1 exactly when intersection_{i in F} S_i is empty. This is the current admission predicate when F is the outside family of the closed repair template, but the theorem addresses arbitrary F. Applying the repair still needs its separate static role and upper-cover conditions. Define tau(empty family)=0.

The preparation question asks whether core-only edits, leaving all Q fixed and F fixed, can make p true in every initially permitted world. Allowing arbitrary knowledge, memory or full commitment cannot remove a fixed hidden incidence; the negative argument will not depend on an observation or scheduler limitation.

## Exact one-label completion identity
Let U add the single hidden label u exactly at the roots F and nowhere else. Then

tau(C+uF)=min(tau(C),1+tau(C_B)).

A cover omitting u is a core cover and costs at least tau(C). A cover including u must additionally cover B using core labels, and needs at least1+tau(C_B). Conversely an optimal core cover or u plus an optimal B cover realizes the corresponding upper bound. Unused labels never help. This covers B empty. Thus the uF completion is native-protected exactly when tau(C_B)>=2, since tau(C) is3 or4; all original floors hold because core supports alone suffice.

## Exact trichotomy of available core information
1. If intersection_{i in F} C_i is nonempty, p=false for every completion: the known common core label persists when hidden labels are added.
2. If tau(C_B)<=1, p=true for every protected completion. Suppose a label x hit every F root. At most one core label y covers B (none needed if B empty), so {x,y} would hit all roots, contradicting tau(S)>=3. In this case the core intersection on F must also be empty, by applying the argument to C itself.
3. Otherwise, the core intersection on F is empty and tau(C_B)>=2. Empty Q has p=true and is protected. The uF completion has p=false and is protected by the identity. Hence the fiber is mixed.

Cases1 and2 cannot overlap because they would imply tau(C)<=2. Together with case3 they exhaust the stated domain. Thus p factors through the supplied core/template information exactly in the two constant cases. This is an exact native-completion criterion for this domain, not a claim that every observer or every restricted hidden ensemble has the same ambiguity.

## Sharp universal preparation conclusion
There exists a core-only preparation achieving p=true for EVERY permitted initial completion if and only if tau(C_B)<=1.

Sufficiency: case2 already supplies p=true, so the zero-edit preparation is sound. This is earned logical certification from the core plus protected-band promise, not an acquired hidden-state record or a nontrivial state-changing preparation.

Necessity: if tau(C_B)>=2, the uF completion is permitted. Any sequence of core-only incidence edits leaves u on every F root, because u is outside P. Therefore p stays false on this world at every slice. This blocks preparation even with full hidden-state knowledge, mandatory commitment, arbitrary memory or extra core-only workspace on the fixed roots. Restricting to uniformly safe band/floor-preserving protocols cannot help. The result does not rely on all-NOOP runs or on failing to discover a path.

The zero-edit sufficiency and the obstruction use the SAME fixed F and same admitted source fiber. They do not turn a failed initial-bit readout into a claim that current-state predicates can never change. In narrower source ensembles, removing a known common core label might change p; the present universal preparation claim includes the valid hidden uF blocker.
