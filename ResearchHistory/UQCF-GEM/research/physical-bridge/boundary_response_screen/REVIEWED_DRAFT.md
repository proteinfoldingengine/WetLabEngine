## 2. Exact interface being granted

Let B be a finite nonempty root-containing prefix tree of known retained addresses, and let X be an otherwise unknown finite prefix extension of B with the same Genesis and literal addresses. Use the inherited unweighted parent-child Laplacian L_X. Let

    S_B = {j in Q^B : sum_B j = 0},
    W_X = Q^X / constant potentials.

The inherited response T_X:S_X -> W_X is the inverse of L_X modulo constants. I_BX extends a source by zero outside B; R_XB restricts a potential class to B. Source and potential maps are different types.

Grant, for the purpose of this screen, every formal zero-sum source j in S_B and the complete response class on the SAME known B:

    Lambda_X,B(j) = R_XB T_X I_BX j.

This is a deliberately generous mathematical interface. The sources do not physically derive event control of every signed input, exact measurement of every potential, or assignment of this operator to an addressed observer view. Those remain conditional. Any smaller physically available source/readout family within this same interface inherits the limitation below. No claim applies to a differently typed family without its own analysis.

The target fact is whether a fixed nonroot v in B is terminal in current X, not merely terminal in the already known B. If the complete domain X is supplied, the question is directly decidable and this proposed inference is unnecessary. The input package here contains B and the response operator, not |X|, all X addresses, an interior readout, or a retained certificate already answering the target.

## 3. Complete response equality

For every admissible prefix extension X of B,

    Lambda_X,B = T_B on S_B.

This is an immediate corollary of foundational P6:

    T_X I_BX = H_BX T_B,       R_XB H_BX = id,

where H_BX is ancestral pullback of potentials. A direct proof also identifies the mechanism. For a root-zero solution psi on B to L_B psi=j, put phi(x)=psi(r_XB(x)). Every omitted subtree is attached to just one vertex of B. The pullback is constant on all its edges, so its internal Laplacian is zero. At retained vertices, only retained edges contribute, giving L_X phi=I_BX j. Connectivity gives uniqueness modulo constants. Restricting phi returns psi.

Thus the whole boundary response contains no information about these unforced pendant extensions. This is equality of exact operators over all j, not a finite sample or a cancellation at one selected source. Changing source amplitudes or taking multiple measurements within this fixed interface cannot defeat operator equality. No physical measurement protocol is asserted.

In particular, take any nonroot leaf v of B. Both X0=B and X1=B union {d}, with d a new child of v, produce exactly T_B. Yet v is terminal only in X0. Therefore no rule using only this B and this complete response map can soundly decide current terminality on the whole declared extension class. The same pair prevents deciding current membership of the named d when such an address is queried.

The conclusion concerns information at B. The fine response and full address domain need not be identical. A zero-source descendant is a real vertex in the model, not an absent vertex. Nor does this compare complete histories or claim physically realized indistinguishable worlds.

## 4. Exact small witness and source-convention control

Zero extension to X gives the root-zero solution

Its restriction is exactly psi for every j. This checks the argument symbolically without running a scientific computation. v changes terminal status while the full two-dimensional boundary response map stays fixed.

## 5. Relation to indexed views and native actions

The theorem compares an unknown current prefix tree X through a known subset B. It does not equate a common carrier's Laplacian with a view-specific incidence sensor. If X is proposed as a particular indexed view, routing the source and readout to that view is itself a premise to derive. A common-carrier field alone does not automatically report which indexed view contains each vertex.

The terminal witness need not be interpreted as changing the global union of an indexed cover. Mathematically one may keep the common carrier Omega=B union {d} fixed, use X0 or X1 for the addressed view, and keep another view equal to Omega in both cases. Both covers have the same union. This observation only shows that the input ambiguity is compatible with a fixed union; it does not supply a native per-view response channel or a physical pair of preparations.

More fundamentally, the response calculation maps a supplied source to a potential on a supplied carrier. Neither the Laplacian nor P6 chooses a retained set or commands a deletion. Even a distinguishable response under the raw-centered convention would still require a justified source actuation, retained output, view binding and action connection before it could provide a native certificate or interaction.
