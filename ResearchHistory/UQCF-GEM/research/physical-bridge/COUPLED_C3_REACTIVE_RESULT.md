# A core-reactive guarded controller for one deficit handoff

Status: proposed analytical result, independent verification/review pending. Scope is COUPLED_C3_REACTIVE_SCOPE.md.

## Objects and interface
There are finitely many labelled nonhost roots and a separate host h. Distinct active pool labels occupy known nonempty patterns W_i covering all nonhost roots. Two other pool labels D,E occur only at h. Fixed hidden backgrounds Q are disjoint from the pool and fresh marker w. Initial supports are exactly those pool incidences plus Q. Positive fixed floors f_v do not exceed initial sizes. The source has 3<=tau<=4, where tau is the minimum hitting-set size.

Select active A on W, m=|W|>=1. A known set K of at most two other active labels covers every nonhost root outside W. Let P be the roots in W hit by K and R=W\P, r=|R|. Freeze orders on P and R. The nonhost script L, of length2m, is: for each p in P add D then remove A at p; then add D at every root in R; then remove A at every root in R. All other pool incidences and Q remain fixed.

The controller receives the CURRENT labelled projection O onto the entire pool, excluding Q and w, after each attempt. Source role patterns, addressed roots/labels, selected goal, K, orders and a reserved fresh marker name are static supplied parameters. Marker freshness and initial admissibility are promises. Neither floor values nor tau nor hidden Q nor marker membership is an input to the policy. There are no other writers, delayed commits, compensations or interleaved macros.

The declared relation extends the existing core-probe guarded grammar to this finite carrier: a request toggles its named incidence only if syntactically valid and the resulting state satisfies every floor and3<=tau<=4. Otherwise it MUST NOOP. Even a valid request may NOOP. Precisely, Outcomes_c(X)={X} union {X^c if admissible and syntactically valid}. No extra commit filter, guaranteed success, fairness or external acknowledgment is assumed. This is not the earlier uniformly-safe-issued-command model: an offered -D request can be inadmissible and rely on rejection.

## Policy from core alone
Let C_t,0<=t<=2m, be the nonhost pool projection after t entries of L, with D removed from h and A absent at h. These are distinct: n_D+(m-n_A)=t, where n_D,n_A count those labels on W; each primitive raises this integer once. The exact labelled template also fixes which request comes next; counts alone are not a promise-free validator.

At the original core projection offer both +w(h) and -D(h). At C_t for t<2m offer only L[t]. At C_2m offer only +A(h). At the target core projection (the complete swap A<->D) offer only -w(h). The four cases are disjoint because source has D at h, interiors have neither A nor D there, and target has A there. Outside these promised reachable templates the policy is empty. This is a set-valued relation, not a new stochastic or physical choice mechanism. Evaluating a fixed template list is not retaining a mutable phase register or reading an event transcript.

## Reachable states and safety proof
Every reachable state lies in the following set. There is the source with w absent or present at h. There are the2m+1 interior prefix states C_t with w present; if f_h<=|E_h(source)|-1, there are also the same interiors with w absent. There are the exact target and its version with w still at h. No marker occurs elsewhere. The absent-marker branch starts by -D directly from the source; the present-marker branch starts by +w then -D. Preparation cannot add w after D has left h. All other changes follow L,+A,-w; NOOPs add no states.

To prove that every claimed change is legal and no additional changes arise, first note that the host after -D has original size with the marker and original size minus one without it. Thus direct deletion is legal exactly when the host floor has slack, provided band safety holds. Nonhost operations never drop below original root sizes; +A restores the host, and deleting w from the target is always floor-safe. Syntactic conditions follow from the script.

For lower band protection map intermediate labels into source labels rootwise. Map w to E. Before any nonhost D addition keep D fixed; once nonhost D is present map D to A. Once A has left all nonhost roots and is added at h, additionally map A to original D. All other labels are fixed. When D->A is used, D is absent at h. When A->D is used, A is absent outside h. Every current support maps into its corresponding original support, including arbitrary Q. Consequently every current hitting set maps to a source hitting set of no greater cardinality, so tau(current)>=tau(source)>=3. The map works with the marker absent as well.

For upper protection, K union {E,A} hits every support until all deficit roots have received D. K already protects P and the roots outside W, so individual covered-root deletions cannot break it. After all R additions, K union {E,D} hits every support, including during all R deletions and terminal host edits. If R is empty either cover works throughout the relevant switch. These covers have size at most4. Marker presence is immaterial because E remains at h. Thus the entire graph stays in band3..4. The direct -D change has the same band protection; its only extra condition is host floor slack. Induction on requests now proves the stated reachable set and guards exactly. In particular, safety is unconditional for permitted outcomes, but relies on the supplied guard relation.

## Rank, resources and terminal boundary
Assign rank0 to the unmarked source,1 to the marked source,2+t to each interior C_t regardless of marker,2m+3 to the marked target and2m+4 to the exact unmarked target. Every committed change strictly increases rank. Every nonterminal reachable state has at least one permitted committed successor. The exact target is the only committed sink and is absorbing under the policy: -w there is syntactically invalid and can only NOOP. Hence every maximal path of committed changes is finite and ends at the exact target. It uses2m+4 changes on the marked branch or2m+2 on the direct branch. This says nothing about how many attempts occur or whether any request succeeds.

The marked branch has peak excess incidences beta=max(1,r), exactly as in the inherited deficit proof: host preparation costs1, covered-root transient duplication costs1, and only the deficit is batched. The direct branch has peak max(0,beta-1); host vacancy offsets those duplications until +A restores the original count. Thus all reachable paths have peak at most beta and use at most one fresh label, removed at the exact target. An interrupted prefix need not attain either branch's peak. A source with tau4 stays at4; a source with tau3 need not preserve exact tau.

Every common O-fiber receives the same policy by construction. In particular, source-with/without-w have identical core and identical two requests; target-with/without-w have identical core and the same cleanup request. The target pair proves a limit: exact-clean-completion is NOT constant on O-fibers, so no function of this current core alone decides it. Both states are reachable even when host floors are saturated. The policy stabilizes the actual target without exposing a reliable stopping certificate.

Arbitrary NOOP execution can stall forever. At the marked source, repeatedly selecting +w also stalls. No deterministic memoryless single-request choice resolves both preparation and advancement at the aliased source in the saturated-host case: choosing -D at the initial source cannot progress, choosing +w cannot leave the marked source, and the frozen two-request action alphabet offers no other action there. This last statement is limited to this policy's source action set, not a universal controller impossibility.

## Scientific meaning and limits
Relative to a supplied current-core channel, the existing guarded relation and static routing/certificate data, a single handoff needs no mutable edit-phase record, marker observation or success acknowledgment. The substantive extension beyond the committed script is safety and complete branching under unobserved preparation, arbitrary NOOPs and slack-floor bypass, with an explicit unobservable-cleanup boundary. General statements above are analytical; finite graph enumeration only verifies the bounded implementation.

The physical or native origin of the core channel, guard enforcement, static source/goal/routing data and initial promises remains OPEN. Request selection/progress is not derived. Arbitrary macro composition, asynchronous observations, external interference, faults, universal native connectivity and physical forces/spacetime/GR derivation are not established. This is a conditional C3 controller result using an inherited C4 repair construction, not closure of broad C3 or C4.
