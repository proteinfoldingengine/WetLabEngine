## Exact construction attempt

Let S be a certified safe intermediate core with absent reserve y and let x be occupied. The existing move performs:

1. Form I_x = {i : x belongs to S_i}.
2. Add y at every root in I_x.
3. Delete x at every root in I_x.

Its endpoint replaces x by y throughout its footprint. The existing proof maintains the original floors and cover protections under its stated hypotheses. Its cost is 2|I_x|, an achieved cost. In producer.py the decisive instruction is:

    loc = [i for i, v in enumerate(a) if v & (1 << x)]

The program then iterates over loc twice. Its input a is a copy of the complete supplied state s. The absent-destination assertion also scans that supplied state. No native rule implementing that scan or the resulting traversal is provided there.

Now try to leave a shared-label reference R fixed while exchanging the source. There are three distinct readings:

**Reference inside the renamed core.** The operation changes every x incidence, including reference incidences. At the complete permutation endpoint both source and reference are relabelled. For example, an overlap statistic |A intersect R| obeys |pi(A) intersect pi(R)| = |A intersect R|. A global label permutation alone therefore does not establish a new endpoint distinction in that statistic. This says nothing against transient relational changes or label-sensitive outputs with an independently justified reference.

**Reference outside the core and disjoint in palette.** This is the protected hidden structure allowed by the theorem. The permutation fixes it. The full endpoint remains label-isomorphic to the source, and an equality-overlap reference cannot compare those disjoint labels. The theorem supplies no new cross-carrier connection or decoder that would turn it into a source record.

**Reference fixed while sharing the exchanged labels.** This is the intended relative interaction. Renaming only source incidences would change relations to such a reference in suitable examples, but that selective action is not the whole-footprint operation on the combined carrier. The disjoint-palette theorem does not certify its safety. It would require an explicit combined carrier, justified boundary/root access and a proof for the modified action. A fixed passive reference also is not automatically a newly written memory: if only a joint source/reference relation changes, accessibility and retention of that joint relation still need a construction.

The last reading is not proved impossible. It is the precise attempted extension that fails to follow from the existing theorem.
