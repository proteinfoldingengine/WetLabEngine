- native same-Genesis pruning and P1 source pushforward;

    actual native event

## 2. Hard admission rule

A substantial new candidate is admitted only if it answers all five before work begins:

1. Which exact owner-held effect/action or access premise is being removed?
2. Which inherited operation produces the candidate relation?
3. Why does that operation act on the designated owner/receiver rather than an arbitrary complementary subsystem?
4. What W_R/W_E/Bell verdict follows before any numerical campaign?
5. What concrete receiver-owned observable consequence is forced, and what falsifies it?

If the producing operation cannot be named from inherited sources, label the candidate NEW ASSUMPTION and do not represent its success as Path-A progress.

## 3. Stop conditions for low-value routes

Do not launch another major campaign whose main result is only one of:

- a new Hilbert-space or Clifford representation;
- a graph-compatible lift;
- a central/effect family with no native selection rule;
- an entropy or capacity bound under a supplied delivery premise;
- a source-only invariant;
- a generic complementary record;
- a software consumer that works once called;
- another module census showing the same ownership relation is absent.

Those may be kept as supporting mathematics, but they are Class C/D unless they directly constrain the owner-held action.

The authorized bounded thermal-bath / other NEW-ASSUMPTION tests may be preserved as boundary evidence, but they must not become the main research rail.

## 4. Primary positive search

Prioritize inherited structures with a chance to produce a receiver-owned action, not merely name a receiver:

### A. Event-codomain ownership

Search for an inherited operation whose codomain is already typed as the retained owner or an owner-local observable algebra. The operation must itself carry source-dependent content into that codomain.

### B. Provenance-bound effect action

Search for an inherited effect/observable whose identity is tied to the same lineage/provenance object as the P1 owner, and prove the actual event changes its state or expectation by a source-dependent amount.

### C. Access-change theorem

Search for an inherited event that changes which owner-local effects are available, while the pre-event receiver remains blind. The access change must be produced by the event, not declared as a READS table or selected record.

### D. Realization-invariant consequence

If ownership cannot be uniquely identified, prove a nonzero owner-local observable contrast across every realization allowed by the actual native premises.

## 5. Standing adversarial gate

For every candidate K:

- W_R passes?
- W_E passes?
- Bell/correlation realization passes?
- If W_R and W_E both pass, K does not determine delivery.
- If only W_R passes, identify the exact inherited source that makes K native.
- If K is equivalent to J_R W = W pi_u, a READS table, copy gate, selected projector, or “R is the receiver” declaration, reject it as target-equivalent.
- If K excludes both, diagnose the type/domain mismatch rather than repairing the candidate after seeing the result.

Do this analytically before expensive verification.

## 6. If no inherited producer exists

Do not respond with another absence census.

Instead formulate the smallest missing physical premise in an explicit premise language and prove:

1. sufficiency for a nonzero receiver-owned consequence;
2. necessity within that stated premise class, if possible;
3. its exact relation to the W_R/W_E freedom;
4. which prior native premises fail to imply it.

A useful negative theorem is one that identifies the minimal missing postulate, not another restatement that delivery is underived.
