## 12. Exact common-center theorem (corrected historical Lemma 13.1)

Let B subset A be a unital inclusion of finite-dimensional complex C*-algebras, with minimal central projections p_i of A and q_j of B. An edge i~j means p_i q_j!=0. Products commute because p_i is central in A. A retained sector q_j straddles if it meets at least two old p_i.

1. Z(A) intersection B = Z(A) intersection Z(B). Indeed an element central in A commutes with B, so if it belongs to B it is central there; the reverse inclusion is immediate.
2. An individual p_i belongs to B iff no q_j meeting it straddles. If p_i belongs to B, item 1 makes it central there, hence a sum of q_j, and each q_j either lies under it or is orthogonal. Conversely, if every q_j meeting p_i meets no other p, then q_j=p_i q_j for those j and p_i=sum_j p_i q_j is a sum of those q_j in B.
3. Full compatibility Z(A) subset B holds iff no q_j straddles, by applying item 2 to every p_i.
4. Form the bipartite incidence graph with vertices p_i and q_j. For each connected component C set e_C=sum_{i in C}p_i. Then e_C=sum_{j in C}q_j and

   K(A,B)=Z(A) intersection B=span{e_C: C a connected component}.

Proof of item 4: since both families sum to 1, and all products linking different components vanish,
sum_{i in C}p_i=sum_{i in C,j}p_i q_j=sum_{i,j in C}p_i q_j=sum_{j in C}q_j.
Thus e_C lies in both centers. If z=sum_i a_i p_i=sum_j b_j q_j lies in the common center, multiplication by each nonzero p_i q_j gives (a_i-b_j)p_i q_j=0, hence a_i=b_j on that edge. These scalar coefficients are constant on each connected component. This proves spanning. Distinct e_C are nonzero orthogonal projections summing to 1, so they are independent. They are the minimal central projections of the common commutative algebra K.

The individual-sector criterion does not describe a basis of all K. For A=C^2 and B=C1, neither old minimal projection lies in B, but K=C1. On X=(o,p,u,v) with u merged into p, A=C^X and B=span{e_o,e_p+e_u,e_v}; K=B, not span{e_o,e_v}. These examples correct the historical span assertion, without refuting items 2 or 3.

Any refinement that restores p_t must separate along that old unit, removing the straddle touching it. This statement does not require losing sums that contain p_t, and does not assert that an individual old unit is necessary for one new accessible effect.

### 13.1 Definition and one-step theorem

  Atilde_j=span{a k:a in A_j,k in K_j^+}=A_j+span(A_j K_j).

# FCV-1 — Proofs for retained closure, descent and comparison

Written before the new adjudication implementation. Review status: self-reviewed mathematical arguments; finite checks and deliberate-defect tests have separate receipts. ## P0 — Scalar structure and linearity

For a finite set X and a specified commutative additive monoid M, finite additivity says mu(A)=sum_{x in A} mu({x}); fiber pushforward is meaningful and additive. No subtraction or vector-space kernel follows for a general M.

For F-valued signed measures with F=Q or R, singleton evaluation is a bijection to F^X: define mu_x(A)=sum_{v in A}x_v, and evaluate singleton sets for the inverse. Pointwise addition and scalar multiplication agree under this bijection. Therefore a finite fiber sum, zero extension, function restriction and pullback are F-linear. This is the explicit linear representation used in the inherited rational diagnostic, not a claim that every signed vector is a physically preparable grade. The symbolic proofs below hold over Q/R. Rational bounded tests check implementations; they are not a density argument for real universality.

## P1 — Admissibility, fiber composition and cumulative kernels

Let X superset Y superset Z be nonempty finite prefix-closed sets with one common Genesis/root. Define r_XY(x) as its longest prefix in Y. Every prefix of x in Z is a prefix of r_XY(x), and conversely a Z-prefix of r_XY(x) is a Z-prefix of x. Their longest elements are equal. Thus r_YZ r_XY=r_XZ. This proves composition from addresses, including identities and repeated pruning.

For z in Z the disjoint fiber identity is

    {x:r_XZ(x)=z} = disjoint union_{y:r_YZ(y)=z} {x:r_XY(x)=y}.

Finite additivity gives (P_YZ P_XY x)_z=sum_{r_XZ(v)=z}x_v=P_XZ x. The matrix product is a representation of this argument, not its premise. Summing over all fibers preserves total grade. In particular each K_j=ker P_0j lies in S_X0, and composition implies K_{j-1} subset K_j. No coarse recentering is substituted.

## P2 — Supplied source section and split loss sequence

Define I_YX on atoms by e_y -> e_{i(y)}; in singleton coordinates it is zero extension. Since r_XY i_YX=id_Y, P_XY I_YX=id_{F_Y}; both preserve total sum. These maps commute with every admissible relabeling because atom inclusion and ancestral fibers do. Hence

    F_X = ker P_XY direct-sum I_YX(F_Y),
    S_X = ker P_XY direct-sum I_YX(S_Y),
    x = (x-I_YX P_XY x) + I_YX P_XY x.

The first term is in ker P; the intersection is zero because PI=id. This is a section supplied by retention, not an arbitrary vector-space splitting. It is not claimed unique among all linear sections.

For X0->X_{j-1}->X_j, let P_a=P_0,j-1 and P_b=P_j-1,j. Restriction of P_a gives the exact sequence

    0 -> K_{j-1} -> K_j -> ker P_b -> 0.

Indeed P_b P_a x=0 for x in K_j. Its kernel is K_{j-1}. Given y in ker P_b, I_0,j-1 y belongs to K_j and P_a I_0,j-1 y=y, proving surjectivity and giving the section. All domains refer to actual nested sets, not equal cardinalities.

For cumulative E_j=I_0j P_0j on F_X0 (E_0=id), E_j^2=E_j and, for i<=j, E_i E_j=E_j E_i=E_j. To see this, I_0j factors through I_0i, and restricting ancestral pruning to X_i is its own X_i->X_j retraction. These address identities establish both products. Therefore D_j=E_{j-1}-E_j is idempotent, D_i D_j=0 for i!=j, and

    K_j = direct-sum_{l=1..j} im D_l,
    im D_j = I_0,j-1(ker P_j-1,j),
    sum_{l=a+1..b} D_l = E_a-E_b.

These are algebraically complementary projectors, not an assertion of orthogonality in a physical metric. Inserting an intermediate retained subset refines the decomposition by the last telescoping identity. Different factorizations with the same endpoints have the same total lost part, though their individual layer labels need not agree.

## P3 — Bare-filtration naturality obstruction (NOT a retained no-go)

Category: finite-dimensional F-vector spaces with fixed-length filtrations 0=K_0 subset ... subset K_m, with all filtration-preserving linear maps. The functors gr_j=K_j/K_{j-1} act by induced quotient maps.

Any natural family of linear maps tau:gr_j -> gr_{j+1} is zero. At any object choose vector-space complements solely to exhibit an automorphism a that acts by 2 on gr_j and identity on gr_{j+1}, preserving the whole flag. Naturality requires tau composed with 2id = id composed with tau, so tau=0 (F=Q/R). This addresses every natural transformation in the declared class; it is stronger than observing that the inclusion becomes zero. Trivial grades are covered automatically.

There is likewise no section of every bare extension 0->A->B->B/A->0 natural under all filtered linear maps when A and B/A are both nonzero. In temporary coordinates B=A direct-sum C, each shear a_u(a,c)=(a+u(c),c) is identity on A and B/A. A natural section s would satisfy a_u s=s for every u:C->A, impossible for a class c with u(c)!=0. P2 does not conflict: the retained category carries actual atoms, inclusions and retractions and excludes those arbitrary shears as structural relabelings.     a^t L_X a = sum_{parent-child edges} (a_child-a_parent)^2.

T_X=q_X G_X|S_X is inverse to l_X. Its zero-mean representative is G_X x; its root-zero representative is G_X x-(G_X x)_root 1. They represent the SAME quotient class, not an identity of sources and potentials. For a root-only carrier S_X=W_X=0 and G_X=0, so the statements remain meaningful.

## P6 — Already-earned boundary comparison and derived response lift

For actual retained inclusion define S_XY:F_X->F_Y by potential restriction. It sends constants to constants and induces R_XY:W_X->W_Y. From retraction define h_YX:F_Y->F_X by h psi=psi composed with r_XY; it induces H_YX:W_Y->W_X. These are typed differently from source P and I. In coordinates S=I^t and h=P^t, but their definitions use set maps, not an added physical metric.

On a prefix tree, a retraction fiber has exactly one retained vertex. Every edge crossing fibers is an original edge between retained vertices. Summing L_X phi over a fiber cancels internal edges and leaves precisely L_Y S phi. Hence

    P_XY L_X = L_Y S_XY.

This is the inherited corrected boundary theorem. Also h psi is constant along every internal fiber edge. At a discarded vertex L_X h psi=0, while at a retained vertex its value is L_Y psi. Thus independently

    L_X h_YX = I_YX L_Y.

It follows on the typed zero-sum sources that

    R_XY T_X = T_Y P_XY,
    T_X I_YX = H_YX T_Y,
    R_XY H_YX = id_WY.

@lru_cache(None)
def all_plane_trees(n: int) -> tuple:
    """All rooted plane trees with exactly n nodes as sorted tuples of addresses."""
    if n < 1:
        return []
    if n == 1:
        return [((),)]

    # Build by distributing n-1 descendants into ordered nonempty/empty child slots.
    # Equivalent: compositions of forest sizes under root.
    results: set[tuple[tuple[int, ...], ...]] = set()

    def forests(remaining: int) -> list[list[tuple[tuple[int, ...], ...]]]:
        """Ordered lists of plane trees whose sizes sum to remaining (any length)."""
        if remaining == 0:
            return [[]]
        out = []
        for first_size in range(1, remaining + 1):
            for t in all_plane_trees(first_size):
                for rest in forests(remaining - first_size):
                    out.append([t] + rest)
        return out

    for child_forest in forests(n - 1):
        atoms = [()]
        for k, subtree in enumerate(child_forest):
            for addr in subtree:
                atoms.append((k,) + addr)
        results.add(tuple(sorted(atoms, key=lambda a: (len(a), a))))
    return tuple(sorted(results))


def is_prefix_closed(atoms: set[tuple[int, ...]]) -> bool:
    if () not in atoms:
        return False
    for a in atoms:
        for i in range(len(a)):
            if a[:i] not in atoms:
                return False
    return True


def closed_pruning_sequences(x0: tuple[tuple[int, ...], ...]) -> list[tuple[tuple[tuple[int, ...], ...], ...]]:
    """All chains X0 >= X1 >= ... >= Xm of prefix-closed rooted subsets (m>=0).
    Represented as tuple of retained-atom tuples (each level sorted).
    Includes the trivial (X0,) sequence.
    """
    atoms = set(x0)
    # All prefix-closed rooted subsets of x0
    subsets = []
    for r in range(1, len(x0) + 1):
        for comb in itertools.combinations(x0, r):
            s = set(comb)
            if is_prefix_closed(s) and () in s and s <= atoms:
                subsets.append(tuple(sorted(s, key=lambda a: (len(a), a))))
    # unique
    subsets = sorted(set(subsets), key=lambda s: (len(s), s))
    # X0 must be present
    x0t = tuple(sorted(x0, key=lambda a: (len(a), a)))
    assert x0t in subsets

    sequences = []

    def rec(current: tuple[tuple[int, ...], ...], chain: list):
        sequences.append(tuple(chain))
        cur_set = set(current)
        for nxt in subsets:
            if len(nxt) < len(current) and set(nxt) < cur_set:
                # single-step: nxt obtained by removing some atoms (any number) but must be
                # reachable as a direct subset; all strict subsets that remain prefix-closed
                # are allowed as next steps (multi-atom removal = simultaneous prune).
                rec(nxt, chain + [nxt])

    rec(x0t, [x0t])
    return sequences

    return {z for z in x0 if retract(z, retained_j) == t}


def shells_for_owner(

    sequence: tuple[tuple[tuple[int, ...], ...], ...],

        shells.append(fibers[l] - fibers[l - 1])
    return shells


def r_inc_minus_record(x: dict, shells: list[set]) -> tuple:
    """Shell sums including A_0 = {t} grade."""
    return tuple(sum(x.get(z, 0) for z in sh) for sh in shells)


def global_shell_partition(x0, sequence, j):
    retained = set(sequence[j])
    parts = []
    for t in sorted(retained, key=lambda a: (len(a), a)):
        shs = shells_for_owner(t, x0, sequence, j)
        for sh in shs:
            if sh:
                parts.append(frozenset(sh))
    return parts


def partition_coarsens(prev, cur) -> bool:
    """True if every block of cur is a union of blocks of prev (cur coarser or equal)."""
    prev = list(prev)
    for b in cur:
        # b must be union of some prev blocks
        covered = set()
        for p in prev:
            if p <= b:
                covered |= p
            elif p & b and not p <= b:
                return False
        if covered != set(b):
            return False
    # all prev blocks used?
    used = set()
    for b in cur:
        for p in prev:
            if p <= b:
                used.add(p)
    return used == set(map(frozenset, prev)) or set(prev) == set(cur)

@lru_cache(None)
def plane_trees(n: int) -> tuple:
    """Independent enumeration of rooted plane trees with n nodes (Catalan-shaped)."""
    if n == 1:
        return (((),),)
    out = set()

    def split_forests(m: int):
        if m == 0:
            yield []
            return
        for k in range(1, m + 1):
            for left in plane_trees(k):
                for right in split_forests(m - k):
                    yield [left] + right

    for forest in split_forests(n - 1):
        nodes = [()]
        for idx, tree in enumerate(forest):
            for addr in tree:
                nodes.append((idx,) + addr)
        out.add(tuple(sorted(nodes, key=lambda x: (len(x), x))))
    return tuple(sorted(out))


def prefix_ok(S: set) -> bool:
    return () in S and all(all(a[:i] in S for i in range(len(a))) for a in S)


def all_closed_chains(X0: tuple) -> list:
    """All nested prefix-closed rooted chains starting at X0."""
    atoms = set(X0)
    subs = []
    for r in range(1, len(X0) + 1):
        for combo in itertools.combinations(X0, r):
            S = set(combo)
            if prefix_ok(S) and S <= atoms:
                subs.append(tuple(sorted(S, key=lambda x: (len(x), x))))
    subs = sorted(set(subs), key=lambda s: (len(s), s))
    X0t = tuple(sorted(X0, key=lambda x: (len(x), x)))
    chains = []

    def walk(cur, path):
        chains.append(tuple(path))
        C = set(cur)
        for nxt in subs:
            if set(nxt) < C:
                walk(nxt, path + [nxt])

    walk(X0t, [X0t])
    return chains


def nearest(z, retained: set):
    for i in range(len(z), -1, -1):
        if z[:i] in retained:
            return z[:i]

def fiber(t, X0, retained):
    return {z for z in X0 if nearest(z, retained) == t}


def owner_shells(t, X0, chain, j):

def shell_sums(grades, shells):

def is_coarser(prev, cur) -> bool:
    prev = list(prev)
    for block in cur:
        cover = set()
        for p in prev:
            if p <= block:
                cover |= p
            elif p & block and not p <= block:
                return False
        if cover != set(block):
            return False
    used = set()
    for block in cur:
        for p in prev:
            if p <= block:
                used.add(p)
    return used == set(map(frozenset, prev)) or set(prev) == set(cur)

def rref(rows, width=None):
    a=[list(map(F,r)) for r in rows]
    n=len(a); m=len(a[0]) if a else (width or 0)
    assert all(len(r)==m for r in a)
    pivots=[];r=0

        pivot=next((k for k in range(r,n) if a[k][c]),None)
        if pivot is None:continue

        scale=a[r][c];a[r]=[v/scale for v in a[r]]

        pivots.append(c);r+=1

def canonical(rows):
    a,_=rref(rows)
    return [r for r in a if any(r)]

def nullspace(rows,width):
    a,p=rref(rows,width);free=[c for c in range(width) if c not in p];out=[]
    for c in free:
        v=[F(0)]*width;v[c]=F(1)
        for row,pivot in enumerate(p):v[pivot]=-a[row][c]
        out.append(v)
    return out

def intersection_basis(left,right):
    # Solve U*a=V*b directly, never reading incidences or graph output.
    if not left or not right:return []
    d=len(left[0]);m=len(left);n=len(right)
    equations=[[F(left[i][k]) for i in range(m)]+[-F(right[j][k]) for j in range(n)] for k in range(d)]
    kernel=nullspace(equations,m+n)
    vectors=[[sum(v[i]*F(left[i][k]) for i in range(m)) for k in range(d)] for v in kernel]
    return canonical(vectors)

def graph_center(old,new):
    # All frozen projectors are diagonal, so multiplication is coordinatewise.
    # This method neither calls rref/intersection nor tests subspace membership.
    m=len(old);n=len(new);d=len(old[0]);adj=[set() for _ in range(m+n)]
    for i,p in enumerate(old):
        for j,q in enumerate(new):
            if any(F(p[k])*F(q[k]) for k in range(d)):
                adj[i].add(m+j);adj[m+j].add(i)
    unseen=set(range(m+n));out=[]
    while unseen:
        todo=[min(unseen)];component=set()
        while todo:
            v=todo.pop()
            if v in component:continue
            component.add(v);todo.extend(adj[v]-component)
        unseen-=component
        left=[sum(F(old[i][k]) for i in component if i<m) for k in range(d)]
        right=[sum(F(new[j-m][k]) for j in component if j>=m) for k in range(d)]
        assert left==right and any(left)
        out.append(left)
    return out
