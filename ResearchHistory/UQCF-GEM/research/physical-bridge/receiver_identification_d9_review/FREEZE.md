**Conventions.** A tree on n addresses is a parent array with parent[0] = none and parent[i] < i (increasing labelling; every rooted tree shape with n addresses occurs). Genesis is 0. A *carrier* is a nonempty prefix-closed subset (equivalently, prefix-closed and containing 0); the empty set is not a carrier. A retained Y is a carrier contained in X. depth(0) = 0. For carriers Z ⊆ W, r_WZ(v) = the longest prefix of v lying in Z, and (P_WZ x)_z = sum over r_WZ(v) = z of x_v. Grade vectors on a carrier are listed in increasing address order. A *rule* assigns to every carrier W and every l with W \ {l} a carrier a map T_{W,l}: Q^W -> Q^{W\{l}}. A *single-pruning sequence* from X to Y is a sequence of removals, each leaving a carrier containing Y, ending at Y. Fractions are written in lowest terms "a/b", integers "a"; grade vectors are lists of such strings.

**Rule panel** (all defined for every carrier W and every leaf l ≠ 0 of W, k = depth(l), anc_d(l) the ancestor at distance d):
- `P1`: T(e_l) = e_{par(l)}; T(e_v) = e_v for v ≠ l (linear).
- `genesis` (Control 16.5(a)): T(e_l) = e_0; others fixed.
- `grandparent` (Control 16.5(b)): T(e_l) = e_{anc_2(l)} if k >= 2, else e_0; others fixed.
- `halfsplit` (non-homogeneous, depth-dependent, non-point): T(e_l) = e_0 if k = 1, else (1/2) e_{anc_1(l)} + (1/2) e_{anc_2(l)}; others fixed.
- `erase`: T(e_l) = 0 (E5 with w = 0); others fixed.
- `double`: T(e_l) = 2 e_{par(l)} (E5 with w = 2 e_1); others fixed.
- `fixed_e2` (absolute weight e_2 everywhere): T(e_l) = e_{anc_2(l)} if k >= 2, else 0; others fixed.
- `leafshift` (violates E3 only): T(e_v) = e_{par(v)} for v = l and for every other leaf v ≠ 0 of W; T(e_v) = e_v for the remaining v.
- `dipole` (violates E4 only): let s < t be the two smallest addresses of W \ {l} that are not ancestors of l; if they exist T(e_l) = e_{par(l)} + e_s - e_t, else T(e_l) = e_{par(l)}; others fixed.
- `sign` (violates E1 only, nonlinear): T(x) = x|_{W\{l}} + x_l e_{par(l)} if x_l >= 0, else x|_{W\{l}} + x_l e_0.

**Condition tests** on every single pruning (W, l) of the universe U16 (section 3): E1 = T(a x + b y) = a T(x) + b T(y) on the test set {e_v, -e_v, 2 e_v, e_l + e_v, e_l - e_v : v ∈ W} with a, b ∈ {1, -1, 2}; E2 = sum T(z) = sum z on that test set; E3 = T(e_v) = e_v for every v ≠ l; E4 = T(e_l) supported on ancestors of l; E5 (weak reading: constrains only the ancestor weights) = there is one sequence (w_1, ..., w_6) with the coefficient of anc_d(l) in T(e_l) equal to w_d for every instance and every d ≤ depth(l); eqP1 = T_{W,l}(z) = P_{W, W\{l}}(z) on the test set.
