## Why even a successful source-to-current derivation is not sufficient by itself

The accepted native_owner_correspondence boundary already constructs two extensions of the SAME native source model:

    delivering event: (x,b) -> (P x, P b),
    blind event:      (x,b) -> (P x, S b).

Here P is the native extensive-grade pushforward, S is literal restriction, and b is an explicitly supplied operational report array. The fixed claimed receiver reads b_a in both extensions. Both start with b=x. The native source objects and native event are identical, while the designated receiver reports differ after the event.

Consider any additional datum G derived only from the shared native source objects, their specified event and their native histories. It could be an incidence cochain, a completely derived weight direction mu, an action variation, or the reviewed polar expression

    J = E* D_mu G_B E delta,

where G_B denotes the branch form to avoid confusing it with the generic added datum. Assume all its inputs are source-side and identical between the two extensions for each fixed preparation.

Then adding this datum cannot distinguish the two report laws. The proof is simply substitution: each extension has the same input to the same construction, so each receives the same added value. Every additional condition involving only those shared objects has the same truth value in both extensions. If one common native model satisfies the new source-side conditions, it can still be expanded with either report law.

Two qualifications are essential:

1. “Same in both extensions” does NOT mean source-independent. The added current can distinguish the two source preparations perfectly and still fail to constrain which operational report contains that distinction.
2. The argument is nonvacuous only on a native model satisfying the added conditions. An inconsistent set of source conditions supplies no physical conclusion.

For the existing witness, X={root,a,u} is a chain and Y={root,a}; inputs x0=e_root and x1=e_root+e_u have the same initial b_a=0. Native P1 gives an added grade at a in the second preparation in BOTH extensions. The delivering report is 0 versus 1; the blind report is 0 versus 0. Any source-only action/current constructed on these same inputs accompanies both alternatives. No action formula is required for this countermodel extension.

This is an elementary consequence of the accepted boundary's existing “forget b” argument, now applied to the newly reviewed action-side tool. It is not presented as a novel general theorem, an archive-wide no-go result, or a new physical discovery.

## What would escape this boundary

The next operation must constrain the actual claimed owner interface, not merely add a source diagnostic. Examples of eligible forms are:

- an inherited event map whose output is already an owner-available record and whose source dependence is derived;
- an inherited relation preserving the relevant state/effect correspondence through the event;
- an inherited access change that makes the source-dependent retained effect available to that owner.

These are obligations, not premises adopted here. A relation that simply declares the desired signal is not a derivation. Name the producing operation and its input/output types, and explain which previously supplied ownership or access premise it removes.

This does NOT require full report transport b'=Px, a unique microscopic implementation, a unique pair map, or a specific action functional. A weaker justified effect can suffice. Nor must a candidate be expressed using the auxiliary report b: if a source-side object itself has independently earned operational ownership/access, the tested interface changes and the above extension argument must be reassessed for that actual interface. We must not use an arbitrary extra b to veto an independently justified source-owned effect.

Likewise, this is not a W_R/W_E score. The accepted P/S report extensions belong to a different explicitly stated model class. For a retained-source effect already fixed by its reduced channel, both W_R and W_E may preserve the same contrast, as the governing output-specific directive explains. Operational correspondence remains the question.
