## 3. Exact calculation and its quantifiers

Write P_p = pi_p tensor I_K. Every realizing isometry has

    W|j> = |j>|e_0> for j=o,p,v,
    W|u> = |p>|e_u>,    <e_0|e_u>=0,

where e_0,e_u are unit vectors in finite K, dim K >= 2. Conversely every such pair realizes C. For the fixed preparations,

    W(rho+ - rho-)W* =
        (pi_p tensor |e_u><e_u| - pi_v tensor |e_0><e_0|)/5.

Hence the fixed binary effect F_a has post-event contrast

    d_a(W) = <e_u|A_a|e_u>/5 >= 0.                         (1)

Its pre-event contrast is zero. In fact the whole algebra generated by the F_a is initially blind: all generators vanish on both u and v sectors, so every generated element acts there by the same scalar.

For one fixed A, every unit vector can occur as e_u. The Rayleigh principle gives the exact attained bound

    min_W d_A(W) = lambda_min(A)/5.                         (2)

Thus, in finite dimension, one fixed positive owner-supported effect separates the pair for every allowed W iff A is positive definite on K. This does not require A=I, a known response scale, or equality of the contrast across implementations. It does require the effect and its owner to be fixed before W is chosen.

For a finite nonempty family choose any fixed positive weights w_a summing to 1 and put S=sum_a w_a A_a. Then

    ker S = intersection_a ker A_a,
    min_W sum_a w_a d_a(W) = lambda_min(S)/5.               (3)

Proof of the kernel identity: <x|S|x> is a positive weighted sum of nonnegative <x|A_a|x>. It vanishes exactly when every A_a^(1/2)x=0, equivalently A_a x=0.

Consequently the following conditions are equivalent in this class:
- For every W, at least one of these fixed tests has positive contrast.
- Their common kernel is zero.
- A fixed positive weighted mixture of the tests has a strictly positive uniform contrast bound.

If classical random choice is actually available, choosing the test independently of the source and retaining its yes/no outcome implements that mixture. This is an optional operational reading; the matrix theorem does not itself supply randomization or a receiver procedure.

Conversely, a nonzero unit x in the common kernel gives an actual admitted blind realization: take e_u=x and any unit e_0 perpendicular to it. Equation (1) then vanishes for every test. The source channel remains exactly C. This is not only failure of the particular weighted mixture.

Finite dimension matters: positivity on every nonzero vector need not give a strictly positive uniform lower bound in infinite dimension. No such extension is claimed.

## 4. Closed-algebra boundary: no hidden weakening of ownership

Let M=C*(I,F_1,...,F_m). In this supported class the conditions in section 3 are also equivalent to

    P_p belongs to M.                                      (4)

If S is positive definite, Fbar=pi_p tensor S has zero eigenspace exactly outside P_p. A polynomial h with h(0)=0 and h(t)=1 on the finitely many positive eigenvalues of S gives h(Fbar)=P_p. Therefore P_p belongs to M.

If x lies in the common kernel, every F_a annihilates both |p>x and |v>e_0. Every element of M has the same scalar action on these two vectors, whereas P_p has values 1 and 0. Thus P_p cannot belong to M. For the corresponding W, the whole algebra M is blind, not merely the selected tests.

When (4) holds, the optimized contrast on M is exactly 1/5 for every W: P_p attains 1/5, and the global trace distance is 1/5. This does not make each originally supplied unsharp effect realization-invariant; equation (2) describes its own contrast.

Therefore:
- At the single-test level, exact calibration can be relaxed to full support.
- With the full generated algebra operationally available, this relaxation is equivalent to the existing owner-projection access premise. It is not a new route around OA*/I*-b.
- This necessity is ONLY for the declared owner-supported class. It is not a theorem for every nonproduct interface or general effect. T-242's joint-effect counterexample and corrected RD-7 scope remain intact.

## 5. A fixed counterexample beyond the three named tests

Use K=E tensor R with basis (00,01,10,11) and

    A_bad = diag(1,1,1,0),
    A_good = diag(1,1/2,1/3,1/4).

Both are nonzero positive effects. Keep the same F_bad=pi_p tensor A_bad in every comparison. W_R uses (e_0,e_u)=(00,01), W_E uses (00,10). Define the Bell representative explicitly by (Phi+,Phi-), where Phi+/-=(00 +/- 11)/sqrt(2). W_star uses (00,11).

| Fixed channel realization | F_bad contrast | F_good contrast |
| --- | --- | --- |
| W_R | 1/5 | 1/10 |
| W_E | 1/5 | 1/15 |
| Bell representative (Phi+,Phi-) | 1/10 | 1/8 |
| W_star | 0 | 1/20 |

All four implement the same C on every source matrix. All candidate tests have zero initial contrast. Thus nonzero support in the p sector plus success on W_R/W_E/this Bell representative does not imply universal separation. W_star reaches the blind mode of A_bad. This is a test of retained-source-sector access, not the old proper-R W_E blindness argument.

For A_good the exact worst-case contrast is 1/20, attained by W_star. It is positive without a calibrated projection read, provided its physical availability and support binding are supplied.

The complementary effects A_bad and |11><11| have no common kernel; their equally weighted average is I/2, so the corresponding mixture has contrast 1/10 for every W. Neither term alone provides that guarantee. This is a completeness illustration, not a proposal to install a new detector.
