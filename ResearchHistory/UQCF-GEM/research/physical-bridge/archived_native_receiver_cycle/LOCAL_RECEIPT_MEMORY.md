# A receiver can recognize a complete source receipt during normalization

In the archived flat four-branch, rank-three complement planner, a site's first local loss marks the end of the initial physical addition phase for that site. The last phase consists solely of physical removals. Thus any subsequent local gain during the same run belongs to the middle phase and completes a guarded transfer. This uses the original planner's phase order, the known start of normalization, the site address, tree, and ordered palette. It requires neither a transfer notification nor a global edit count. Repetitions of a holding leave the recognition rule unchanged.

For a recognized gain of x, if every previously held label is below x, the local decoder proved in TWO_SITE_RECEIPT.md reconstructs the entire original v16.26 release dictionary. The receiver change belongs to the stock dynamics. The listener is a new analytical readout over successive receiver holdings. The archive stores a global path; no original receiver-owned history writer has been established.
