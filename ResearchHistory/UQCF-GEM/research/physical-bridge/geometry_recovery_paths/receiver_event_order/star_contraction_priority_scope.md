# Same receiver under a change of chart priority

The first proof allows the receiver pair to depend on chart priority. Fix instead the original A, B, source alternatives, and original optimum H that survives both cuts. Move B to the front of the chart ordering and leave the relative order of all others fixed. Before replaying, the original H should still be first among minimum covers in either arm, since it contains B and pairwise order between covers containing B is preserved. As first holder B should then make zero deletions during the whole contraction in both arms. Test with exactly the same physical roles and source leaves on the original small traces; the earlier reindexing check recomputed the roles. This distinguishes a receiver dictated by the prepared incidences alone from one dictated by incidences plus priority.
