# Receiver records and the fixed-receiver chart priority control

Two different source withdrawals in the supplied preparation can lead to different P1 values at the same receiver's first loss of an existing leaf. Promoting that physical receiver to the front of the chart order suppresses all its contraction writes in both arms. The same minimum cover remains selected. Full normalization erases the source difference at its canonical endpoint. The proof establishes a conditional process on ordered input, with origin of this ordering and physical enactment open.
