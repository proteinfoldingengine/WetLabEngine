## Why the two kinds of order differ

Consider two ordinary v16.26 deletions by different charts, both initially legal on the same fixed rooted tree. Each chart's local tip test depends only on its own row. For deletions at distinct sites, the remaining-holder test at either site is unaffected by the other deletion. Both orders succeed and end with the same indexed rows. The same is true at a shared site with at least three original holders. Any difference in the historical attribution of those two successful edits is lost to functions of that common endpoint alone.

If the two edits concern the same site with exactly two original holders, the first deletion leaves the other chart holding the only copy. The second deletion would change the union and is illegal. All further ordinary deletions preserve that survivor. This proves the distinction for every initially enabled pair by different charts under this primitive. The bit at tip 6 records the identity of the successful withdrawal. It does not encode a relative ordering of two executions at tip 6, since only one can execute. The earlier bit at tip 5 concerns the relative order of two successful edits at different sites.

def encoded(value):

def pinned(path, expected):
    data = path.read_bytes()

    return data


def module(path, name, identity):
    pinned(path, identity)
    spec = spec_from_file_location(name, path)
    mod = module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def rows(charts, columns):
    return tuple((0,) + tuple(i for i, col in enumerate(columns, 1) if c in col)
                 for c in charts)


def as_rows(data):
    return tuple(map(tuple, data))


def reachable_by_columns(charts, start):
    """Independent construction using nonempty subsets of each holder column."""
    choices = []
    for v in range(1, 8):
        holders = [c for c, row in zip(charts, start) if v in row]
        choices.append([subset for n in range(1, len(holders) + 1)
                        for subset in combinations(holders, n)])
    states = {rows(charts, cols) for cols in product(*choices)}
    edges = {}
    for s in states:
        for t in states:
            if s == t or not all(set(b) <= set(a) for a, b in zip(s, t)):
                continue
            removed = [(i, v) for i, (a, b) in enumerate(zip(s, t)) for v in set(a) - set(b)]
            if len(removed) == 1:
                edges[s, *removed[0]] = t
    return states, edges


def native_graph(atom, verify, p, start):
    work, seen, events = [start], set(), {}
    while work:
        state = work.pop()
        if state in seen:
            continue
        seen.add(state)
        for i, row in enumerate(state):
            for leaf in row[1:]:
                try:
                    d = atom.atomic(p, state, i, leaf)
                except ValueError as ex:
                    assert str(ex) == "same union"
                    continue
                verify.verify_atomic(d)
                events[state, i, leaf] = d
                work.append(as_rows(d["after"]))
    return seen, events


def match_edges(states, events, reference_states, reference_edges):
    assert states == reference_states
    assert {e: as_rows(d["after"]) for e, d in events.items()} == reference_edges


def trace_successors(mod, build):
    # Interpose only after the genuine atom returns its ordinary certificate.
    reads = Counter()
    class ReadTrace(dict):
        def __getitem__(self, key):
            reads[key] += 1
            return super().__getitem__(key)
    original = mod.atomic
    def traced(*args):
        return ReadTrace(original(*args))
    with patch.object(mod, "atomic", traced):
        result = build()
    return result, dict(reads)
