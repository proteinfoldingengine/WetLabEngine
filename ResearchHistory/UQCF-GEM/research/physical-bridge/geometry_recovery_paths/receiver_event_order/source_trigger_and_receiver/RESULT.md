# A running four-child writer can distinguish two source withdrawals at a fixed target

A chart can gain a branch or lose a leaf on its next edit depending on which neighbor just withdrew from a junction. Both withdrawals are legal, give identical cover and trigger values, and leave the chart's own prior unchanged. The same original v16.53 normalization frame is already running when the source acts. Its next recursive call reads the surviving holders from the live atlas. This establishes a path from a supplied source occurrence to an uninvolved chart's next software write without a second external launch. The occurrence, the initially running computation, ordering and physical access remain supplied or open.

## One execution with two alternative source actions

Use a root with four children. W and S each have two leaves. X and Y are leaves. Initially A and B both hold W and its two leaves. All three charts hold S, and only C holds its two leaves. Only A holds X. B and C hold Y. The common Pin belongs to all three. C is identified before either intervention as the sole chart holding the two descendants of S. The fixed target is (2,1,1), the minimum number of charts to cover the children of the root, W and S respectively.

Take the root-child order W,S,X,Y and chart order A,C,B. The original outer writer first completes two real deletions on W. C remains unchanged. When the routine reaches S, its original child-call frame is already active. Before the parent-coverage check reads the state, the test supplies one v16.26 atomic action. Either A or B drops S, which is terminal within either actor's view. The union of the indexed views still covers every ambient vertex. All three cover coordinates keep the same value, both receipts give zero increment and a false trigger, and the receiver's entire indexed row and P1 grade are identical at that instant.

| Actor releasing S | Holders read by the original S call | First ensuing edit of C | Addressed P1 consequence with unit fine grades |
| --- | --- | --- | --- |
| A | C, B | C adds W | C's Pin grade falls from 5 to 2 and its new W grade is 3 |
| B | A, C | C drops the first leaf below S | C's grade at S rises from 1 to 2 |

Both runs reach the same canonical endpoint. Under the displayed numbering C's initial mask is 369. The first new masks are 371 and 337. The opposite edits can be read without waiting for termination.

The original child call reads membership in S from its current outer state, constructs its local label list in the existing priority, normalizes the binary subtree, then projects each inner step back to those actual outer charts. Its binary target is one. It fills the two leaves on the participating labels, retains both on the earliest label and removes them from later labels. Thus C keeps its leaves when the earlier neighbor releases S. C's first edit then occurs in the outer cover-two expansion, which adds a missing root child. When the later neighbor releases, C loses its first descendant in the binary call. The source receipt is never passed to either routine. Only the actor's one junction bit is changed by the intervention.

The first-edit direction separates the actors precisely when C lies between them in chart priority. If C is first it retains both inner leaves in both arms. If it is last it loses both in both. The complete C traces in these outer positions also agree in every tested ordering. All six chart orders and all 24 orders of the four root children were replayed with the physical roles retained. Of 144 orders, 48 distinguish the two single withdrawals at C's first edit and 96 give identical complete C traces. In 24 of the 48 positives W had already caused two edits before the source intervention. Inner sibling order is fixed in the sweep.

Five histories were tested per order: neither withdrawal, A only, B only, A then B and B then A. If both bare holders release before the child reads its labels, their actions commute and the same atlas reaches the same pending child call. Every subsequent global state agrees. If neither releases, C's complete trace always matches at least one single-withdrawal history. In the middle-rank cases it matches the release by the later neighbor. The proposed source alternatives must therefore be specified to infer the actor. An arbitrary occurrence cannot be detected from this trace alone.

## Why a full-bin displacement does not supply the flat response

For a flat four-tip input of exact cover three, the original algorithm uses the complements of the holders. With k charts the capacity of each bin is k−1. After removing duplicate complementary memberships, each chart occupies its earliest missing-tip bin. In the priority used for the computation, the canonical single holders of the four tips are 0,0,1,2. Chart 0's complementary goal is therefore the third bin and every other chart's goal is the first. This canonical pattern is unchanged for k≥3 because palettes uses the minimum-width three-chart solution.

When chart 0 is first processed, its destination could be full only if every other chart first missed the third tip. Each of them would then hold the first two tips, and chart 0 would hold the third. Any holder of the fourth would give a cover of size at most two with chart 0 or one of those other charts, contrary to the starting cover. After chart 0 is at its goal, it is outside every later destination. A chart requesting the first bin is also outside it. That bin thus has at most k−2 occupants. Consequently no transfer displaces an incumbent. Each chart's ordered local trace is determined by its own initial mask, its priority position, k and the fixed label orders. It first discards duplicate complementary memberships, can transfer once directly to its goal, and finishes its prescribed complementary target. A change in when another chart is edited need not appear in this record.

In the four-chart extension, 2,952 of 50,625 nonempty-holder-set stars have target three. The original verified paths give 44 individual trace classes at fixed chart position and starting mask. All 30,528 eligible remote-withdrawal/bystander comparisons at fixed target agree.
