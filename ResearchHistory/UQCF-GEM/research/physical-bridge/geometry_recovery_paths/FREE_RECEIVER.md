On the balanced 25-chart preparation, two source deletions of grade 1 have different consequences for the numerical states that chart 12 can reach. After source cut 662 it can end with just one unit-grade leaf. After cut 718 it always retains at least two. This distinction uses chart 12's current P1 entries with their leaf names erased. The shortest history that can distinguish the sources this way has **931 receiver deletions**. If only the current root grade is available, the sole distinguishing value is **3,176**, attainable after 1,305 receiver deletions. The two source choices also share a complete receiver history. None of these conclusions requires a supplied normalization destination.

## General classification for the native deletion rule

Fix a finite rooted tree equal to the union of the indexed, prefix-closed chart views. Each chart contains the root. A native move removes a single nonroot leaf of one local chart and preserves the union. Let L be the leaves of the union other than the root. The empty L case covers a root-only tree. Write H(t) for the initial holders of a tip t, with the given source event already applied when comparing histories.

**Terminal states.** Assign each t in L to exactly one chart in H(t), independently for each tip. Give each chart the root and all ancestors of its assigned tips. These are precisely the reachable terminal states. In a terminal state, a maximal nonroot member of a chart must be a global tip. Otherwise a global tip below it belongs to another chart, which therefore also holds the maximal member and permits its deletion. A duplicated global tip likewise permits a deletion. Conversely, every listed endpoint preserves the union and is contained chartwise in the initial state. Delete surplus members deepest first. Each remains covered by the designated final family. At the endpoint each nonroot local leaf is private, proving terminality. Every run is finite since each deletion lowers the total number of incidences.

**Visible charts and histories.** For any fixed nonempty collection C of charts, put M(t) = H(t) intersect C. In a terminal state the visible owner of t may be any member of M(t). An additional outcome “held only outside” is possible precisely when H(t) has an outside member. Take the product of these sets over all tips. For any such visible endpoint the possible complete visible deletion words are exactly the orderings of the removed chart-vertex pairs in which a removed descendant precedes its removed ancestor within that chart. Necessity follows from prefix closure. For sufficiency choose an outside keeper wherever needed, run the specified visible word first, then remove the outside surplus. Each intermediate state contains a covering final family. This proof also shows that all local prefixes can be extended. Outside steps are omitted from the visible word; no global clock or outside side channel has been assumed.

**One common history always survives.** Across any collection of external-only histories with the same original visible charts and union, assign every global tip that has any visible holder to one fixed such holder. The visible endpoint and a single ordering of its local surplus are then common to every history. Complete any outside cleanup after that word. This construction proves that even the combined records of all nonsource charts cannot identify the source choice on every unrestricted complete run. Some receiver edits can nevertheless be forced. In the registered dead-stub control, a chart must shed an internal vertex whose only fine descendant is privately held outside. After either external source event its own root grade rises from 9 to 13. The forced local change carries the same numerical content in both arms.

For a single receiver this theorem gives all subsets between its forced and available global tips. The exact root distribution follows by grouping tips under each child w of the fine root. If m optional receiver tips lie in that branch, there are 2^m assignments. Exactly one of them drops the whole branch when no tip there is forced, and zero do when a tip is forced. A dropped branch transfers its full fine subtotal to the root. Multiply these one-branch counting polynomials and shift by the fine root's own grade. An independent calculation uses the individual grades of all optional tips in the actual chart-12 fixture.
