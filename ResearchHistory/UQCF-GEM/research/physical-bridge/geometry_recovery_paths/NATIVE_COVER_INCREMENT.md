## Why one chart becomes necessary

Write H(v) for the charts holding root child v. Suppose C is the set of charts forced by private root children and C covers all root children. Every cover contains C, so C is the unique minimum cover. A legal deletion of v at i leaves the private witnesses in place. All other children are still covered by C. If C contains a remaining holder of v, C is still the unique minimum. Otherwise the new minimum covers are exactly C union {j} for each remaining holder j of v. This follows because C is mandatory and adjoining any such j suffices. The argument uses only membership and the historical union-preserving deletion rule.
