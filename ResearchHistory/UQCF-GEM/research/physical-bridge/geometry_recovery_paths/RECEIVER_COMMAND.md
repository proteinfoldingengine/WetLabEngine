# What makes the archived caller choose view 12?

The historical recovery program computes a source-dependent deletion address. In the two-unit example its returned list has the sole entry $(12,2)$, and the program passes that entry to the original deletion operation. On the same preparation after the one-unit source deletion the same selector returns an empty list. The specific work value $W_{0,12}$ that changes from 1997 to 1994 between sources is dispensable for that decision. The four source links to the original neighbors of view 12 account for the decision under the matched tests below. The caller is a global one-step recovery calculation. Its invocation by a native pruning event and a receiver-owned read remain open.

## What each operation reads and writes

**INHERITED.** The common fine tree, integer grades, P1 fiber aggregation, v16.26 atomic deletion, v15.40 dual-coordinate work and v15.43 carrier are those pinned by the archived fixture. In this embedding $W_{ij}$ sums $s_v^2$ over the symmetric difference of the two views, with $s_v$ the fine subtree subtotal. The baseline minimum is $\mu=1984$. The historic reporting helper and proof harness are existing software at the indicated commits. Neither is assumed to be a physical update law.

**SUPPLIED.** Use the same 25-view preparation, the specified source event in chart $A=0$, and the comparison chart $B=12$. A legal atom removes one nonroot local leaf from a named chart and keeps the union. Calling the one-step selector additionally asks which single deletion restores degree four in the graph of minimum-work pairs. The full carrier has further tests.

## Why the direct work value cannot decide the next one-step command

Each next atom changes one chart. If its editor differs from both $A$ and $B$, it leaves $W_{AB}$ alone. Otherwise deleting a leaf of subtotal $s$ changes the pair value by $+s^2$ or $-s^2$. At the two genuine source-only states the excesses over $\mu$ of the direct pair are 13 and 10. Both lie strictly between $3^2$ and $4^2$. For every integer subtotal and either sign the two values have identical three-way comparisons to $\mu$ after an edit. This statement compares the two candidate numbers at a *fixed* background, editor and leaf, including the sign fixed by the other chart's membership. Other table entries are then identical by construction.

Some old minimum edge avoids any one editor in each of these preparations. If any changed work drops below $\mu$, its new minimum edges are confined to one star and cannot form a four-regular graph on 25 vertices. Otherwise the degree test uses only which entries tie $\mu$. Thus swapping just the two symmetric entries representing $W_{AB}$ changes the report entry and preserves every candidate decision in either background. This does not assert numerical irrelevance of $W_{AB}$ for all geometries, for later edits or for every downstream consumer.

As a realizable control, delete raw unit leaf 718 from $A$ instead. Its cut is $\{8,13\}$, so $B$ holds it; the direct work becomes 1999. On both unit-source cases the original four $A$ edges increase by one, while the old nonneighbors had excess at least four. This isolates $A$ in the minimum graph. An edit elsewhere can restore at most one of the four incident edges it needs. If $A$ edits again, all four original neighbors must regain their missing edges to $A$ because degrees elsewhere have not changed. Each has work $\mu+1$ against $A$. The required deletion would have subtotal one and would be absent at all four neighbors. Every eligible unit leaf in $A$ is absent from at most two labels. The exclusive depth-two child cannot be deleted. Neither unit arm therefore has any one-deletion degree recovery.

## Which four relations determine the named command

Let $E=N_{\rm initial}(B)=\{7,11,13,17\}$ and $D=N_{\rm initial}(A)=\{1,4,5,20\}$. Before a $B$ edit, $B$ has the same four minimum neighbors $E$ in both source arms. The work from $A$ to those neighbors, in that order, is $(1987,1989,1989,1989)$ after the unit event and $(1984,1984,1984,1984)$ after the two-unit event. In either source background every other $A$ entry, including the direct entry to $B$, exceeds the minimum.

For the fixed command that removes leaf $U=2$ at $B$, each member of $E$ also holds $U$ and loses its old minimum edge to $B$ as that work increases by four. Each member of $D$ lacks $U$ and obtains a minimum edge to $B$ as its old excess four falls to zero. These are the only changes of minimum membership in $B$'s row. In particular $W_{AB}$ stays above $\mu$ after its decrease of four for either allowed input value. All edges disjoint from $A,B$ have their original torus membership.

Hold the rest of the table at either actual source background. Assign each $W_{Ae}$ independently its one- or two-unit value and assign $W_{AB}$ either 1997 or 1994, preserving symmetry. Before the $B$ edit, the selected minimum links from $A$ to $E$ count the two-edge paths from $A$ to $B$. After the $B$ edit these same links determine the degree of $A$. If even one is missing, $A$ has degree at most three. If all four are present, the minimum graph is exactly the original torus with the roles of $A$ and $B$ exchanged. Every vertex has degree four. This proves necessity and sufficiency for the named command in this family. Across all $2\times16\times2=64$ inputs exactly four pass, one per background and direct value. Mixed tables isolate the software dependence and need not be attainable tree states. Only genuine states were submitted to the full carrier.

The exact raw universe contains 32,575 admissible one-view deletions per genuine source arm. The original selector and an independent construction give the same complete candidate list. The check reconstructs legality from per-vertex support and child lists, reconstructs work from grade-grouped membership bitsets, and obtains the required new neighbors of each editor from the graph with that editor removed. It tests every proper subset of the four links. The certificate records each complete raw legal set using inclusive address intervals for every view.

The result distinguishes two ways a source value gets used. The direct pair value has an existing path into a global report. A different part of the same work table selects a chart-12 command under an externally invoked recovery objective. The unchanged native legal interface and the equal local root under the same command locate the remaining step. A native use of the four-link condition, or another inherited operation that makes the changed relation available to the chart itself, would have to supply the receiver-side invocation.
