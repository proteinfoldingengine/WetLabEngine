v10.0 introduced the smallest explicit protected-sector extension capable of carrying a

\[
\mathcal Q_{\rm src}\simeq\mathbb N.
\]

The immediate danger was that this could reduce to arbitrary subsystem counting.

v10.1 tests that danger.

The result is sharp:

- counting Hilbert tensor factors is rejected;
- a factorization-independent token number can be consistent only when promoted to an
  explicit grading/superselection operator \(N\);
- that grading composes additively,
  \[
  N_{A\otimes B}=N_A\otimes I+I\otimes N_B;
  \]
- vacuum spectators, swaps, indistinguishable-particle symmetrization, basis changes, and
  number-preserving redistribution/merger dynamics preserve the total grade;
- genuine creation or annihilation changes grade and therefore is not a structure-preserving

- no nontrivial grading operator is canonically generated by a bare Hilbert space.

Thus v10.0 survives its naturality audit only in the stronger form

\[
\boxed{
\text{protected source token}
\equiv
\text{explicit conserved grading}.

That grading remains a new physical axiom.

No gravity or force law is derived.

## 1. Bare-Hilbert naturality no-go

Suppose one attempts to assign to every finite-dimensional Hilbert space \(\mathcal H\) a
canonical number operator \(N_{\mathcal H}\) using no structure beyond the Hilbert space itself.

Naturality under every unitary \(U\in U(\mathcal H)\) requires

\[
UN_{\mathcal H}U^\dagger=N_{\mathcal H}.
\]

Therefore

\[
N_{\mathcal H}
\]

lies in the commutant of the full unitary group.

The commutant of the defining irreducible unitary action is one-dimensional:

\[
\boxed{
N_{\mathcal H}=c_{\dim\mathcal H}I.
}
\]

The executable commutant calculation gives dimension one for

\[
d=2,3,4.
\]

Hence a bare Hilbert space cannot supply nontrivial internal token-number sectors.

Scalar assignments can still obey tensor additivity,

\[
c_{d_1d_2}=c_{d_1}+c_{d_2}.
\]

For example,

\[
c_d=\lambda\log d
\]

does so for arbitrary \(\lambda\).

But these are exactly the old nonunique scalar amount characters; they do not provide a
protected integer grading.

## 2. Correct protected object: a graded Hilbert space

The minimal viable object is therefore not

\[
\mathcal H
\]

but

\[
\boxed{
(\mathcal H,N),
}
\]

where \(N\) is a nonnegative integer-spectrum operator.

Tensor composition is

\[
\boxed{
N_{A\otimes B}
=
N_A\otimes I_B
+
I_A\otimes N_B.
}
\]

For a two-level occupancy object,

\[
N=\begin{pmatrix}0&0\\0&1\end{pmatrix}.
\]

Two copies have

\[
N_{\rm tot}
=
N\otimes I+I\otimes N
\]

with spectrum

\[
\boxed{
0,1,1,2.
}
\]

The one-token sector is two-dimensional because the token can occupy either factor.

For three factors, both parenthesizations give exactly

\[
N_1+N_2+N_3.
\]

The executable associativity error is zero.

## 3. Vacuum spectator neutrality

Let the monoidal vacuum have

\[
N_{\rm vac}=0.
\]

Then

\[
N_{A\otimes{\rm vac}}
=
N_A\otimes1+I_A\otimes0
\cong
N_A.
\]

Thus adding an empty spectator does not create source amount.

The checker obtains exact equality.

This fixes an important semantic problem: **not every extra tensor factor is a source token**.

## 4. Swaps and indistinguishable-particle symmetrization

For two identical graded factors, the swap operator \(S\) obeys

\[
\boxed{
[S,N_{\rm tot}]=0.
}
\]

Therefore the symmetric and antisymmetric projectors

\[
P_\pm=\frac12(I\pm S)
\]

also commute with total grade.

So passing to indistinguishable-particle symmetry sectors does not change protected amount.

The token count is a property of the total graded object, not of labels attached to individual
distinguishable subsystems.

## 5. Number-preserving merger / redistribution

A protected count must survive formation of composite or bound configurations.

The executable control uses two truncated bosonic modes with local occupation operator

\[
N=a^\dagger a.
\]

The two-mode total operator is

\[
N_{\rm tot}
=
N_1+N_2.
\]

Use the beam-splitter generator

\[
K=a_1^\dagger a_2-a_1a_2^\dagger.
\]

It satisfies

\[
\boxed{
[K,N_{\rm tot}]=0.
}
\]

Hence

\[
U(\theta)=e^{\theta K}
\]

preserves total token number exactly.

Starting from the two-token state

\[
|1,1\rangle,
\]

the interaction redistributes occupation among the factors, creating a superposition within the
total-\(N=2\) sector.

The checker finds

\[
\Pr(N_{\rm tot}=2)=1,
\]

\[
\langle N_{\rm tot}\rangle=2,
\]

and variance zero to machine precision.

Therefore merger, binding, delocalization, or subsystem redistribution can alter where the
source is represented while preserving total protected amount.

This also clarifies the semantics:

\[
\boxed{
n
\text{ counts protected constituents, not macroscopic source objects.}
}
\]

Two constituents forming one bound object still have \(n=2\).

## 6. Splitting versus creation

A mere refactorization may spread one protected token over several factors.

For example,

\[
|1\rangle
\longmapsto
\frac{|10\rangle+|01\rangle}{\sqrt2}
\]

intertwines the grading:

\[
\boxed{
N_{\rm out}V=VN_{\rm in}.
}
\]

The executable intertwining defect is zero.

But the map

\[
|1\rangle\longmapsto|11\rangle
\]

would change grade

\[
1\to2.
\]

Its intertwining defect is exactly nonzero.

Thus:

\[
\boxed{
\text{refactorization may redistribute grade but cannot change total }n.
}
\]

A true source-creation or annihilation event requires an operation outside the
grading-preserving processing class.

## 7. Naive factor count is rejected

The same abstract Hilbert space

\[
\mathbb C^4
\]

can be presented as one four-level factor or as

\[
\mathbb C^2\otimes\mathbb C^2.
\]

Naive tensor-factor count therefore gives

\[
1
\]

or

\[
2
\]

for the same Hilbert space.

So:

\[
\boxed{
\textbf{Hilbert-factor count is not a natural protected source amount.}
}
\]

The remedy is to carry \(N\) as part of the structure.

Under an isomorphism \(W\),

\[
N\mapsto WNW^\dagger.
\]

Its spectrum and sector multiplicities are unchanged.

Thus the grading survives basis changes and arbitrary representation changes **provided the
grading is transported with the object**.

## 8. The processing class must be revised explicitly

If token number is protected, not every quantum operation is source-blind admissible.

An ordinary Hadamard on the local occupancy basis mixes

\[
|0\rangle
\quad\text{and}\quad
|1\rangle
\]

and therefore

\[
[H,N]\ne0.
\]

Such an operation changes protected source sectors.

By contrast, a phase operation diagonal in number commutes with \(N\).

Thus the protected-token architecture requires that source-blind processing either:

1. preserve \(N\) exactly; or
2. act inside fixed-\(N\) sectors.

This does not invalidate the v9.221 processing-equivalence theorem. That theorem applies
within each protected sector.

v10.1 makes explicit what the protected sector actually means.

## 10. Irreducible boundary

The naturality audit also strengthens the new-axiom boundary.

Therefore the grading cannot be hidden inside ordinary quantum kinematics.

It must be supplied as:

- a superselection grading;

- a protected representation label;

Nothing in v9 selects which one.

So:

\[
\boxed{
\textbf{protected token number is mathematically consistent,

}
