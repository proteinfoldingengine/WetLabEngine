# UQCF-GEM v7.23 — Quotient Correspondence to UCP Classification

## Main result

Let

\[
\pi:X\to Y
\]

be a finite retained quotient and let

\[
F_y=\pi^{-1}(y),\qquad n_y=|F_y|.
\]

Take the reversible pair-groupoid algebras

\[
\mathcal A_X=M_{|X|}(\mathbb C),
\qquad
\mathcal A_Y=M_{|Y|}(\mathbb C).
\]

Require a coarse-to-fine observable map

\[
\Phi:\mathcal A_Y\to\mathcal A_X
\]

to be UCP, to reproduce the canonical classical ledger pullback

\[
\Phi(E_{yy})=P_y=\sum_{x\in F_y}E_{xx},
\]

and to be invariant under permutations within every fine pruning fiber.

Define

\[
v_y=\frac1{\sqrt{n_y}}\sum_{x\in F_y}|x\rangle,
\qquad
V|y\rangle=v_y,
\]

and

\[
Q_y=P_y-|v_y\rangle\langle v_y|.
\]

Then every such map is

\[
\boxed{
\Phi_C(A)
=
V(C\circ A)V^\dagger
+
\sum_y A_{yy}Q_y,
}
\]

where

\[
\boxed{
C\succeq0,\qquad C_{yy}=1.
}
\]

Conversely every correlation matrix \(C\) defines such a UCP map.

## Consequence 1 — unequal fibers are allowed

The \(*\)-homomorphism obstruction from v7.21 was real, but it was specifically
an obstruction to multiplicative embedding.

It is not an obstruction to UCP coarse-graining.

The executable audit uses pruning fibers of cardinalities

\[
1,\quad2,\quad3
\]

and verifies UCP maps for all three tested correlation kernels.

Thus

\[
\boxed{
\text{unequal multiplicity obstructs }*\text{-homomorphism, not UCP}.
}
\]

## Consequence 2 — the channel is not unique

Two extreme admissible choices are:

\[
C=I,
\]

which removes all coarse off-diagonal coherence, and

\[
C_{yz}=1,
\]

which preserves the normalized uniform coherence mode between every pair of
pruning fibers.

Both are UCP.
Both obey the same fiber symmetry.
Both reproduce exactly the same classical retained-observable pullback.

More generally, every

\[
C\succeq0,\qquad \operatorname{diag}C=1
\]

is allowed.

Therefore

\[
\boxed{
R_\pi+\text{counting symmetry}
\not\Rightarrow
\text{unique noncommutative channel}.
}
\]

## Exact missing datum

The remaining freedom is a positive-definite cross-fiber coherence kernel

\[
C(y,z).
\]

Equivalently,

\[
C_{yz}=\langle\xi_y,\xi_z\rangle
\]

for unit vectors attached to the correspondence.

This is the finite manifestation of the standard correspondence/GNS picture:
a CP map is represented by a correspondence together with distinguished vector
data. The bare correspondence does not determine those matrix coefficients.

So it must not yet be identified with the channel kernel.
