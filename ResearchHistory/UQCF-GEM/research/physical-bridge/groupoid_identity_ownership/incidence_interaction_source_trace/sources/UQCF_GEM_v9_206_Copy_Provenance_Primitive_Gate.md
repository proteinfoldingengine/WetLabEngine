\[
\Pi_1:\mathfrak E(\bar\rho)\to\mathcal D(\mathcal H_S),

\Pi_1(\{R_n\})=R_1.

\[

\frac12\rho_0^{\otimes n}

\[
\Pi_1(R^{(\eta)})=\bar\rho

This includes every one-copy expectation value, one-copy spectrum, one-copy marginal,
one-copy completion property, and any source label or token count held fixed across the

Thus:

\[
\boxed{

\]

This is a simple factorization theorem, not an empirical claim.

## 3. A canonical second-order witness

Let \(S_{12}\) be the complete-copy SWAP between the two source specimens.

For any one-copy density \(\rho\),

\[
\operatorname{Tr}[(\rho\otimes\rho)S_{12}]
=
\operatorname{Tr}\rho^2.
\]

For the retained source

\[
\bar\rho=
\frac12\rho_0+\frac12\rho_1,
\qquad
\operatorname{Tr}\bar\rho^2=\frac12.

For the v9.205 family,

\[
\boxed{

Hence

\[
\boxed{

=
\frac{\langle S_{12}\rangle-\operatorname{Tr}\bar\rho^2}

Thus the family is physically distinguishable at copy order two even though all frozen
one-copy data agree.

## 6. Why native token count does not solve the problem

Earlier replica candidates introduced finite source-token sets and additive token count.

That structure distinguishes **how many** declared source tokens exist.

It does not determine which exchangeable quantum preparation state is assigned to those
tokens. At fixed token count \(n\), every \(R_n^{(\eta)}\) uses the same number of source
copies.

Likewise, graph relabeling and copy permutation symmetry constrain how copy labels transform,
but not which joint density is physically prepared.

Therefore:

\[
\boxed{
\text{copy count}
\neq
\text{copy provenance}.
}
\]

A count can be native or stipulated while the joint preparation relation remains free.

## 7. Why canonical disjoint tensor product is not yet a physical selector

For two specified disjoint densities \(\rho\) and \(\sigma\), the frozen tensor-product
construction supplies

\[
\rho\otimes\sigma
\]

as a valid realization.

If one **adds** the strict preparation law

\[
R_{m+n}=R_m\otimes R_n
\]

for repeated-source joins, then \(R_n=\bar\rho^{\otimes n}\) follows and \(\eta=0\).

But this is precisely the strict product/independence premise distinguished in v9.175.
Associativity and projective consistency alone do not imply it.

So iid preparation can be selected, but only by adding an independence law.

## 8. Broader hierarchy warning

The one-scalar selector is special to the restricted \(R_n^{(\eta)}\) family.

The earlier v9.175 construction gave exchangeable, deletion-consistent all-count preparation
families parameterized by a measure \(\mu\), with moments \(M_k\). It proved:

that broader family.

The correct general statement is:

\[
\boxed{

restriction on the preparation family}.
}
\]

Otherwise a full preparation measure or equivalent extension hierarchy may be required.

\[
\boxed{

\longmapsto

For a more general preparation class, \(\mathsf P\) may need a measure, moment hierarchy,
or another higher-order object.

The current frozen architecture contains no canonical such section in the inspected
definitions.
