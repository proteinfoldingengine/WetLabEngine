Date: 2026-10-07.

## Mathematical definition and limits

The hitting number tau(E) is the minimum cardinality of a label set intersecting every original root support.

The accepted target-four theorem applies only to n=3 or n=4 distinct singleton roots, original floors 1, prescribed permutation endpoints, sequential incidence toggles, and one globally unused auxiliary label w.

One auxiliary can be reused across all disjoint cycles of the prescribed permutation within that bounded carrier. The constructive event count is 2m+2c, where m is the number of moved roots and c is the number of nontrivial cycles. This is not a general minimum-length result.

The 2l+2 optimality statement applies only to one nontrivial cycle for n=3 in the declared sequential native-toggle model. The n=4 endpoint-only swap demonstrates w is not universally necessary.

For n>4, the same buffer method preserves tau=n and therefore does not preserve the required upper bound tau<=4.
