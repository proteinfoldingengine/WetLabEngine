# Independent review of the archived lineage repair rule

The archived routine writes an unprotected parent's existing array row when the only initial difference is at its unprotected leaf. The parent row is read again in the same implementation. On a tree with fixed common protected rows, the exact first-arrival sweep equals the distance through unprotected rows. The proof assumes exact real arithmetic. Real binary64 execution can map distinct large collinear inputs to one result.

The [proof and prospective checks](https://github.com/proteinfoldingengine/WetLabEngine/blob/c0326d996c9ffa39a603b91a7a3b2e91966613bf/ResearchHistory/UQCF-GEM/research/physical-bridge/lineage_repair_trace/ASSESSMENT.md) preceded the finite replay.
