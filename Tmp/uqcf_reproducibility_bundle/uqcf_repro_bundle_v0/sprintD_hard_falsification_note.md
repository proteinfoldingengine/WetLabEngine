## 3. Domain-of-validity statement

### Current domain claim
The current bridge version is only claimed for:

- the retained-coherence reduced-law framework
- the closure interval and nearby selector basin already studied
- the current minimal DESI-facing proxy layer

It is **not** yet claimed as:
- a full cosmological Boltzmann theory
- a global symbolic proof over all admissible deformations
- a final high-redshift or lensing-complete theory

### Domain falsification rule
If the bridge is forced outside this domain and fails there, that does **not** by itself falsify the present scoped claim.

But if the bridge fails:
- inside the certified closure neighborhood,
- inside the tested broad selector basin,
- or inside the locked DESI-facing proxy comparison grid,

then the present bridge version is wrong on its own stated terms.
