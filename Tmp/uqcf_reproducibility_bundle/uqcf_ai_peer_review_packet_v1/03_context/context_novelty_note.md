### Overlap with UQCF-GEM
UQCF-GEM overlaps with this class in that it uses:
- an effective dimensional deficit variable
- diffusion / spectral-response style observables
- fixed-point language
- closure / RG-like reasoning

### Difference
The current bridge does not begin from the standard asymptotic-safety program or a conventional renormalization-group derivation of running couplings.
Instead, it builds a retained-coherence bridge around:
- screened pruning-flow
- participation feedback

- and a shell–microstate microscopic architecture

So the overlap is conceptual, not identity.

### Current claim level
UQCF-GEM can reasonably be described as **adjacent to running-dimension / fixed-point cosmology ideas**, but not yet as a derivation inside asymptotic safety.

### Overlap with UQCF-GEM
UQCF-GEM overlaps with this class in that it treats:
- retained coherence as a structural primitive
- closure as an emergent selected state
- and the microscopic layer as a shell–microstate architecture rather than a standard field-only cosmology

The current bridge is more explicitly compressed around:
- a reduced-law fixed-point map

- and a concrete bridge-to-observable proxy

### Current claim level
UQCF-GEM can reasonably be described as **an emergent/coherence-adjacent cosmological bridge with explicit reduced dynamics**, but not yet as an externally validated emergent-spacetime theory.
