# Package Inventory

- `ROUND16_RESULTS.json`  
  Machine-readable closeout state.

- `ROUND16_RESULTS_TABLE.csv`  
  Compact table of the systems, outcomes, and evidence levels.

- `ROUND16_CLOSEOUT.md`  
  Narrative closeout and decision framing.

- `ROUND16_RESULTS_EXPLAINED.md`  
  Plain-language explanation of what the results mean and why the neutrals matter.

- `ROUND16_X_POSTS.md`  
  Public-facing post options with a slightly cheeky tone.

This package is a closeout/explanation bundle. It does not include every source PDF from the GitHub repo. It is meant to sit alongside the GitHub publication and summarize what the round showed.
