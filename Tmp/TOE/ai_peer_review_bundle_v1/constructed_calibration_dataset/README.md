# Constructed Calibration Dataset

These files are **constructed stand-in data** generated from the restricted family used during theorem development.

They are suitable for:
- exercising the calibration runner
- anchoring a first internal calibration packet
- validating the workflow end to end

They are **not** the user's measured or external baseline data.

## Files
- constructed_baseline_anchor.json
- constructed_screened_family.jsonl

## Purpose
Because no real calibration arrays are currently available, these constructed files allow the project to proceed through the first full anchored calibration cycle.
