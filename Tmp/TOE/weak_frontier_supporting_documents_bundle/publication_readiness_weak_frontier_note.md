# Publication Readiness Note — Weak Frontier Status

## Purpose

This note consolidates the current scientific status of the weakest vector-side frontier and identifies what is now strong enough to describe publicly versus what still must be framed cautiously.

It is intended as the current publication-readiness note for the weak-channel portion of the program.

---

## 1. Current scientific status

The weak frontier was originally the main unresolved seam between:

- ultra-weak multifrequency
- noisy contrast
- and possible boundary-like transitional cases

Recent work expanded that seam into a structured weak-channel program and tested it across:
- targeted seam cases
- rescue-vs-regression tests
- fresh weak-channel validation families
- and a 4-axis weak-frontier sweep

That body of work now supports a clearer scientific picture.

---

## 2. What is now supported strongly

### A. weak_signal_multifrequency
This state now appears repeatedly in fresh weak-channel families and does not look like a one-off artifact.

### B. sub_boundary_weak_multifrequency
This state now has the strongest new support among the weak refinements.
It repeated across targeted seam cases and broader sweeps.
It is no longer best treated as a single awkward miss.

### C. noisy_scalar_like
This state remains stable and well-preserved.
It continues to behave as the correct sink for genuinely degraded weak-channel cases.

Together, these three states form a lower weak-channel ladder that now looks scientifically real.

---

## 3. What remains provisional

### weak_multifrequency_boundary_crossover
This state proved useful as an abstaining selector state for certain crossover cases.

However, in the broader 4-axis weak-frontier sweep it did **not** emerge as a stable repeated region.

That means the correct current scientific framing is:

> the crossover state is useful as a local abstention mechanism, but is not yet established as a broadly repeated regime.

This is the most important caution for publication.

---

## 4. Best current weak-frontier framing

The strongest honest framing is:

> the weak frontier now supports a repeatable lower ladder of:
- weak_signal_multifrequency
- sub_boundary_weak_multifrequency
- noisy_scalar_like

while the explicit crossover state remains provisional and should be described as an abstention tool rather than a fully certified regime.

That is the correct current public framing.

---

## 5. What is strong enough to publish now

The following claims are now strong enough for a conservative public memo or progress report:

1. the vector family contains a real weak-channel frontier
2. that weak frontier does not collapse directly from weak multifrequency into noise
3. an intermediate sub-boundary weak state appears to repeat
4. noisy contrast remains distinct and stable
5. the top of the weak seam is still under refinement and should be framed cautiously

Those claims are supportable.

---

## 6. What should not yet be overclaimed

It would still be premature to claim:

- that the weak frontier is fully solved
- that the crossover state is already a stable repeated region
- that the selector boundaries are final
- or that all future out-of-suite weak families will fall cleanly into the current weak-channel map

Those remain open.

---

## 7. Publication recommendation

### Recommended now
- internal research memorandum
- conservative public progress note
- publication section framed as:
  - established results
  - provisional frontier
  - explicit remaining open seam

### Not yet recommended
- strong final public claim that the weak-channel selector is fully generalized
- final model narrative implying the weak frontier is closed

That would still be too strong.

---

## 8. Best one-sentence summary

The best current publication-ready summary is:

> the weak vector-side frontier now shows a repeatable lower ladder of weak-signal, sub-boundary, and noisy states, while the crossover at the top of that frontier remains a useful but still provisional abstention region.

That is the strongest honest publication sentence available now.
