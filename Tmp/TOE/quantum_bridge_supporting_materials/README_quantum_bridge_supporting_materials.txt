Quantum Bridge Supporting Materials
==================================

This package contains the main result tables and validation outputs for the final bridge architecture:
1. Global locked two-timescale retained-memory operator
2. Global pair refinement (early_dv_flip, early_v_range)
3. Minimal local seam rule for the narrow short-scale frontier

Key top-level files to review first:
- full_bridge_final_closure_comparison.csv
- final_validation_simple_seam_rule.csv
- conditional_band_override_test.csv
- local_band_override_test.csv
- fresh_out_of_slice_closure_test.csv

A JSON manifest is also included.
