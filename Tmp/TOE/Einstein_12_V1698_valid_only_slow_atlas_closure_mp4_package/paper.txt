The rules of Global Retained-Atlas Closure

The rules are now clear enough to state as a formal closure definition.

A retained atlas is globally closed only if all of the following hold.

Rule 1 — Retained chart coverage

There must be a family of retained local charts:

A_R = { U_i, G_i, S_i, O_i, P_i }

where each chart carries:

U_i  = local chart / patch
G_i  = generated local algebra
S_i  = source assignment
O_i  = retained-order / provenance ordering
P_i  = support / provenance witness data

Closure requires the charts to cover the retained object:

⋃ U_i = retained domain

In the Python proof, this was the chart coverage condition.

Rule 2 — Pairwise retained transition maps

For every nonempty overlap:

U_i ∩ U_j ≠ ∅

there must be a retained transition map:

T_ij : G_i → G_j

This is not just a coordinate map. It must transport the generated algebra while preserving the retained source/order/support ledger.

In the proof:

T_ij = B_j^-1 B_i

That gave explicit transition maps between local retained charts.

Rule 3 — Inverse consistency

Every transition must have a valid reverse transition:

T_ji T_ij = I

or, in residual form:

|| T_ji T_ij − I || ≤ ε_inv

This blocks fake one-way chart stitching.

In the proof, valid atlas inverse residuals passed, while transition-corrupt nulls failed.

Rule 4 — Triple-overlap cocycle closure

For every admissible triple overlap:

U_i ∩ U_j ∩ U_k ≠ ∅

the transition maps must close:

T_ki T_jk T_ij = I

or:

|| T_ki T_jk T_ij − I || ≤ ε_cocycle

This is the local-to-global compatibility rule. It says the atlas is not merely pairwise consistent; it is globally glueable.

This is one of the central rules.

Rule 5 — Retained-loop holonomy closure

For every admissible retained loop:

U_i → U_j → U_k → ... → U_i

the composed transport must close:

H_loop = T_i...k ... T_jk T_ij

and for flat/admissible closure:

|| H_loop − I || ≤ ε_holonomy

If holonomy is nontrivial, it must be accounted for as a legitimate curvature/source defect, not as an untracked closure error.

In our proof, the valid retained atlas had identity retained-loop holonomy. The nulls broke closure.

Rule 6 — Retained source/order/support admissibility

This is the part that classical atlas theory does not have.

Even if the matrices close, the retained atlas fails if the ledger is corrupted:

source assignment must remain admissible
support assignment must remain admissible
retained-order signature must remain admissible

So the closure condition is not merely:

matrix cocycle closes

It is:

matrix cocycle closes
and retained provenance/order/source ledger remains admissible

That is one of the novel rules.

Rule 7 — Witness-certified filling

Higher-order closure cannot be inferred from graph cycles alone.

You need witness layers:

W1 = edge witness
W2 = face/path filling witness
W3 = cell/cycle filling witness

The closure stack requires:

W1 → W2 → W3

with each layer carrying retained provenance/order/source compatibility.

This prevents a fake closure where a graph has loops but no admissible retained filling.

Rule 8 — Source-current compatibility

There must be an explicit retained source/provenance current:

J_R

and every W3-certified cell must have an associated current row.

A source-free cell is allowed:

J_R = 0

but missing J_R is not allowed.

That distinction was important in the validator repair.

Boundary closure must be checked with signed orientation:

⟨δA_R, ∂C⟩

not with a scalar proxy.

The rule is:

signed boundary residual = decomposed deltaA_R + boundary_pairing

A scalar “boundary score” is not enough.

A closed-only atlas is not enough. An open-only atlas is not enough.
