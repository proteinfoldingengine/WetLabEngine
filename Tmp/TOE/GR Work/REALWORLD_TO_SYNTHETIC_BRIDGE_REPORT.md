# Executive Summary

The retained-atlas framework did not begin as a synthetic simulation project.

It began from repeated real-world observations suggesting that passive burden measurements alone were insufficient to characterize true recoverability.

The synthetic V723/V724 assay family was later constructed as a controlled instrumentation framework to isolate and stress-test those observations.

The resulting synthetic assays demonstrated:

- passive burden observables collapsing toward chance,
- active perturbation-response observables remaining strongly discriminative,
- null-collapse behavior,
- monotonic k-gap scaling,
- and geometry-like restorative organization emerging operationally.

The strongest supported result is not “GR solved.”

The strongest supported result is:

> Active perturbation-response observables retained measurable information about hidden restorative capacity that passive burden observables could not reconstruct.

# Real-World Origin

The framework originated from repeated observations in real systems where:

- static burden indicators appeared similar,
- but adaptive recovery diverged,
- collapse thresholds emerged unexpectedly,
- and intervention response exposed hidden reserve not visible passively.

This motivated the operational hypothesis:

> Recoverability may fundamentally be an intervention-observability property rather than a purely passive geometric property.

# Why Synthetic Assays Were Built

Real systems are difficult to isolate scientifically because they contain:

- hidden variables,
- incomplete observability,
- uncontrolled perturbations,
- non-repeatable trajectories,
- noisy interventions,
- and missing counterfactuals.

The synthetic retained-atlas framework was therefore created to provide:

- paired counterfactual controls,
- perturbation-response isolation,
- null-collapse testing,
- parameter sweeps,
- stress testing,
- and reproducible falsifiable experiments.

The synthetic system is not the endpoint.

It is the instrumentation layer for studying the recoverability hypothesis.

# V723: Passive-Equivalent Specificity Closure

V723 introduced paired passive-equivalent counterfactuals:

- same initial state
- same perturbation
- same amplitudes
- same target field
- same stochastic noise
- same observation window
- only restorative capacity k changed

Results:

- adm_z AUC = 1.000
- passive metrics ≈ 0.500

Interpretation:

Passive burden observables became non-discriminative,
while active restoration remained perfectly discriminative.
