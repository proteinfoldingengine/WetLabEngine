# Claim Boundaries

## Allowed

We can say:

```text
The software recoverability simulation produces bounded conformal / metric-like response dynamics from observable information/recoverability variables.
```

We can also say:

```text
The Ω-like response factor is directionally predictable after spatial coarse-graining.
```

## Not allowed

Do not claim:

```text
physical GR
Einstein equations
actual spacetime curvature
coordinate-covariant metric tensor
real-world validation
```

## Clean public sentence

```text
We are not claiming to create physical GR. We are reporting that a software recoverability simulation produces GR-like / conformal / metric-like response geometry from information-theoretic dynamics.
```
