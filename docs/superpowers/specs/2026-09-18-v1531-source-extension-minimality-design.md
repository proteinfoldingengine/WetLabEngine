## 1. Purpose

v15.30 established that none of the four strongest frozen provenance/source candidates supplies a certified typed common carrier connecting microscopic representatives inside one exact source fiber

```text
F(q) = { x in C1 : B1 x = q }
```

to provenance/source identity.

The next lawful question is not which new source semantics gives the most gravity-like response.

It is:

> What is the minimal representation-theoretic structure that any new source-semantics axiom would have to provide in order to distinguish representatives in one fixed q-fiber and become eligible for a later source-to-cycle coupling audit?

v15.31 therefore classifies the admissible **source-extension envelope** implied by the already-certified finite pre-time representation structure. It adds no physical source-semantics axiom and does not choose an extension by downstream performance.

## 2. Frozen claim boundary

## 4. Minimal source-extension interface

A future source-semantics axiom capable of distinguishing two representatives with the same q must supply more information than Q alone.

v15.31 models the minimal linear interface as an equivariant source extension

```text
0 -> K -> S -> Q -> 0
```

together with a typed microscopic lift

```text
Phi : C1 -> S
```

satisfying

```text
p o Phi = B1
```

where `p : S -> Q` is the extension projection.

For `x1-x2 in Z`, the extension is genuinely fiber-sensitive only if

```text
Phi(x1) != Phi(x2)
```

for at least one exact same-q pair.

Equivalently, the induced fiber-sensitive component must be nonzero on `Z`.

This construction is an **interface definition**, not a physical assertion that nature uses a linear extension.

## 5. Gate A — exact representation inventory

Reconstruct the exact `G` actions on `C1`, `Q`, `Z`, and `Y_cyc`.

Verify exactly:

1. `B1` is G-equivariant;
2. `Z = ker(B1)` is G-invariant;
3. the quotient action on Q is well defined;
4. the target action used by v15.28 is reproduced without basis-dependent choices;
5. all group laws close exactly.

Floating linear algebra may be used only as a diagnostic. Rank, character, orbit, and intertwiner adjudication must use exact integer/rational arithmetic whenever the inherited action permits it.

Failure to reproduce the exact inherited representations stops the gate as:

`UNRESOLVED_SOURCE_EXTENSION_REPRESENTATION_AUDIT`.

## 6. Gate B — semisimplicity / extension-class boundary

Because G is finite and the working linear field has characteristic zero, finite-dimensional rational/real representations are expected to be semisimple. v15.31 must verify the applicable hypotheses for the exact inherited representation category rather than merely citing Maschke's theorem.

The gate must distinguish:

### Rational/real linear category

Determine whether every exact sequence

```text
0 -> K -> S -> Q -> 0
```

splits G-equivariantly.

If so, any linear extension is representation-equivalent to

```text
S ~= Q direct_sum K
```

and representation theory alone does not provide a canonical semantic binding between coarse q and the new fiber-sensitive component.

### Integral-lattice category

Do not infer integral splitting from rational/real semisimplicity.

Audit whether the exact inherited integer lattice admits inequivalent integral extension data that disappear after tensoring with Q or R. If the current archive does not define the integral module category strongly enough to adjudicate this, record that boundary explicitly rather than inventing one.

No nontrivial extension class may be called physical merely because it exists mathematically.

## 7. Gate C — fiber-sensitive channel classification

The new semantic content must respond to exact same-q differences in Z.

Before choosing any provenance semantics, classify the exact equivariant linear channel space

```text
Hom_G(Z, Y_cyc).
```

This answers a representation-only question:

> If a future source axiom supplied a covariant fiber distinction, how many independent symmetry-compatible ways could that distinction affect the already-defined cycle-response target?

Determine exactly:

- dimension of `Hom_G(Z,Y_cyc)`;
- irreducible/common-isotypic content where exact decomposition is available;
- multiplicities;
- orbit/character cross-checks;
- basis-change invariance;
- whether any one-dimensional projective channel is canonically singled out.

This is not permission to identify Z itself with physical provenance.

## 8. Gate D — conditional minimal-kernel characterization

Gate D is deliberately conditional.

If

```text
dim Hom_G(Z,Y_cyc) > 1
```

then representation-level nonuniqueness is already proved and the primary gate may stop as
`FIBER_EXTENSION_CHANNELS_EXIST_BUT_NONUNIQUE`. A complete irreducible decomposition is **not** required merely to strengthen an already decisive nonuniqueness result. Record any inexpensive rank/character diagnostics, but do not spend the gate reconstructing representation theory that cannot change the adjudication.

If

```text
dim Hom_G(Z,Y_cyc) = 1
```

then characterize the unique nonzero intertwiner exactly. Let K be its image representation. Verify:

1. K is G-invariant;
2. the map `Z -> K` is nonzero and exact;
3. the inclusion/map `K -> Y_cyc` is exact;
4. the projective channel is basis invariant;
5. no second inequivalent projective channel appears after admissible basis changes or quotient conventions.

Record the dimension of K, kernel dimension, image rank, exact projective hash, and character/orbit cross-checks.

If `dim Hom_G(Z,Y_cyc)=0`, Gate D is skipped.

This early-stop rule keeps v15.31 focused on the minimum fact needed to adjudicate the source-extension interface. No semantic meaning is attached to K.

## 9. Gate E — source-semantics information contract

Use Gates A-D to derive the **minimal information contract** that a future explicitly approved source-semantics axiom must provide.

At minimum the contract must state, without downstream fitting:

1. the physical provenance/source carrier P;
2. its transformation law under the inherited pre-time symmetries;
3. a typed map from microscopic source representatives or exact q-fiber differences into P;
4. a typed relation from P to one of the admissible kernel types K, or an independently motivated reason why the linear extension framework is inapplicable;
5. the equivalence/gauge structure on P;
6. whether the map is linear, affine, integral, nonlinear, categorical, or otherwise;
7. why the relation is physically motivated independently of gravity behavior.

v15.31 must not fill in these items. It only states which are mathematically missing.

## 10. Preregistered outcomes

### `UNRESOLVED_SOURCE_EXTENSION_REPRESENTATION_AUDIT`

Inherited exact representations cannot be reproduced or their category is insufficiently specified.

### `NO_FIBER_SENSITIVE_TARGET_CHANNEL`

`Hom_G(Z,Y_cyc)=0`.

Under the frozen linear symmetry structure, extra same-q information cannot affect the current cycle-response target through any equivariant linear channel. Any continuation would require a changed target, symmetry, or nonlinear/new structure.

### `FIBER_EXTENSION_CHANNELS_EXIST_BUT_NONUNIQUE`

One or more fiber-sensitive channels exist, but representation theory leaves multiple inequivalent channel/kernel choices or multiplicities.

This is the expected generic branch-stop result unless exact computation shows otherwise.

### `UNIQUE_MINIMAL_FIBER_CHANNEL_UP_TO_SCALE`

Exactly one nontrivial minimal G-equivariant fiber-sensitive channel survives up to overall scale and all declared equivalences.

This would be a major structural result, but it still would **not** identify physical provenance or constitute a new source-semantics axiom.

### `INTEGRAL_EXTENSION_STRUCTURE_REQUIRES_SEPARATE_AXIOM`

The rational/real category splits but nontrivial integral-lattice extension structure survives or cannot be excluded. Any physical use of that structure requires a separately justified integral source semantics.

## 14. Scientific interpretation discipline

A positive representation-theoretic result means only that the frozen pre-time symmetry structure constrains the **form of information** a future source-semantics axiom could use.

It does not prove:

- that physical provenance is linear;
- that the fiber kernel is a physical degree of freedom;
- that one historical provenance carrier realizes the kernel;
- that a unique coupling law exists on the full source carrier;
- that coupling magnitude is fixed;
- that gravity is derived;
- that a gravity canary may be used to choose among surviving semantics.

The central distinction is:

```text
representation eligibility != physical source semantics
```
