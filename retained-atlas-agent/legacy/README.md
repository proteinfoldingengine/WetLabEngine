# Legacy Retained Atlas Loop

The former GitHub Actions workflow `retained_atlas_loop.yml` is archived here for provenance.

It is **historical and inactive**. The workflow's prior Actions run history and generated research artifacts remain part of the public record. This archive is not an instruction to resume the old autonomous loop.

The legacy workflow directly used an OpenAI API key, generated and executed Python, updated research state/prompts, and pushed generated outputs back to `main`. The reactivated UQCF-GEM/WetLab program uses stricter scientific governance, branch/PR review, provenance manifests, preregistration, held-out validation, and explicit claim adjudication.

Do not restore this file under `.github/workflows/` without a new reviewed design and explicit authorization.
