# V309B — Regime Validity Check for Ablation

## Question
Are the reachability-law ablation metrics interpretable in a non-degenerate regime, or is the current harness still too sparse for component testing?

## Hypothesis
If the harness is valid, then the full score should show nonzero variance, nonzero trigger rate, and enough positive bad cases for ablation comparisons to be meaningful.

## Method
Run a fixed-seed toy simulation with the same core reachability components, but first verify the regime is non-degenerate before interpreting any component drops.

Measure:
- bad_rate
- score variance
- trigger_rate
- AUC
- balanced_accuracy
- accuracy
- phase_counts
- validity_gate

## Controls
- Fixed seeds
- Shared configuration across score variants
- No threshold tuning
- Interpret component ablation only if the full score is non-degenerate

## Results
Will be generated by the Python harness.

## Interpretation
If the validity gate fails, the result is a harness/regime failure, not a law failure.

## Failure / Caveat
Ablation comparisons are not meaningful if bad_rate is too low, score variance is zero, or trigger rate is zero.

## Decision
branch if validity gate fails; otherwise continue

## Next
Smallest useful next test: if valid, run a held-out component ablation in the same regime; if invalid, redesign the regime to target bad_rate in 0.20–0.40.
